-solv- / -solu-松开；解开ほどく；解くLatin solvere / solutus

来自拉丁语 solvere（松开；过去分词 solutus）。solve“解开 → 解决”、dis-（解散 → 溶解、解散）、ab-（解开束缚 → 绝对的、赦免）、in-（无法偿付 → 破产的）。⚠️ resolve 已在 Day 7 学过；solid（固体的）来自 solidus，不同源。ラテン語 solvere（ほどく、過去分詞 solutus）から。solve「解く → 解決する」、dis-（ばらばらにほどく → 溶かす・解散する）、ab-（束縛を解く → 絶対の・免除する）、in-（支払えない → 支払不能の）。⚠️ resolve は Day 7 に既出。solid は solidus 由来で別。

-term- / -termin-界限；终点境界；終点Latin terminus

来自拉丁语 terminus（界碑、终点）。term“期限；条款；术语”、terminal“终点站”、de-（彻底划界 → 决定）、ex-（赶出界外 → 消灭）、in- + -able（没有终点的 → 冗长的）。⚠️ terminate 已学过；thermal（热的）来自希腊语 thermos，不同源。ラテン語 terminus（境界石・終点）から。term「期間・条件・用語」、terminal「終着駅」、de-（境界をはっきり定める → 決定する）、ex-（境界の外へ追う → 駆除する）、in-（終わりのない → 果てしない）。⚠️ terminate は既出。thermal はギリシャ語 thermos 由来で別。

-ann- / -enn-年年Latin annus

来自拉丁语 annus（年），复合词中变为 -enn-。annual“每年的”、anniversary“每年转回来的日子 → 周年纪念”、bi-（两…）：biannual“一年两次”、per-（贯穿）：perennial“常年的”、mill-（千）：millennium“千年”。⚠️ annoy（使烦恼）、announce（宣布）都与“年”无关。ラテン語 annus（年）から。複合語では -enn-。annual「毎年の」、anniversary「毎年巡る日 → 記念日」、biannual「年 2 回の」、perennial「長年続く」、millennium「千年」。⚠️ annoy・announce は「年」と無関係。

-graph- / -gram-写；画書く；描くGreek graphein / gramma

来自希腊语 graphein（写、画）和 gramma（写下的东西）。photo-（光）：photograph“用光画 → 照片”、auto-（自己）：autograph“亲笔签名”、para-（旁边）：paragraph“段落”、dia-（穿过）：diagram“图表”、pro-（预先）：program“预先写好的 → 节目、计划”、bio-（生命）：biography“传记”。⚠️ grammar 也同源；但 grab、graph paper 的 grab 无关。ギリシャ語 graphein（書く・描く）と gramma（書かれたもの）から。photograph「光で描く → 写真」、autograph「自筆 → サイン」、paragraph「段落」、diagram「図表」、program「前もって書かれたもの → 番組・計画」、biography「伝記」。⚠️ grammar も同源。

-fac- / -fec- / -fic-做；制作する；作るLatin facere / factus

来自拉丁语 facere（做）。在复合词中变成 -fic- / -fec-。efficient“做得出来的 → 高效的”，defect“做坏了 → 缺陷”，sufficient“在下面做够 → 足够的”。⚠️ Day 6 的 beneficiary 也含 fic；而 face（脸）来自 facies，和“做”不是一回事。ラテン語 facere（する・作る）から。複合語では -fic- / -fec- に変化。efficient「やり遂げる → 効率的」、defect「作り損ない → 欠陥」、sufficient「下から満たす → 十分な」。⚠️ Day 6 の beneficiary も fic を含む。face（顔）は facies 由来で別。

-form-形状；形式形；形式Latin forma

来自拉丁语 forma（形状）。con-（与…同形 → 遵守）、re-（重新塑形 → 改革）、uni-（一种形状 → 制服、统一的）、trans-（变形 → 转变）。inform“赋予形状 → 告知”也同源。⚠️ formidable（可怕的）来自 formido“恐惧”，不同源。ラテン語 forma（形）から。con-（同じ形にする → 従う）、re-（形を作り直す → 改革）、uni-（一つの形 → 制服・均一な）、trans-（形を変える → 変える）。inform「形を与える → 知らせる」も同源。⚠️ formidable は formido「恐怖」由来で別。

-gen-产生；种类生む；種類Latin genus / generare

来自拉丁语 genus（出身、种类）和 generare（产生）。generate“产生”，general“同一种类的 → 一般的”，generous“出身高贵的 → 慷慨的”，genuine“天生的 → 真正的”。⚠️ engine 也同源（ingenium“天赋、巧思”）。ラテン語 genus（生まれ・種類）と generare（生む）から。generate「生み出す」、general「同じ種類の → 一般の」、generous「生まれのよい → 気前のよい」、genuine「生まれつきの → 本物の」。⚠️ engine も同源（ingenium「才能・工夫」）。

-plic- / -ply-折叠折る；重ねるLatin plicare

来自拉丁语 plicare（折叠）。ap-（折向 → 应用、申请）、com-（折在一起 → 复杂的 / 遵守）、im-（折进去 → 含义）、du-（折两次 → 复制）、multi-（折很多次 → 乘、增加）、ex-（展开 → 明确的）。⚠️ supply 来自 supplere“填满”，comply 也受 complere 影响，严格说属 -ple-“填满”，这里作为拼写形近的易混词一起记。ラテン語 plicare（折る）から。ap-（〜へ折る → 応用・申し込む）、com-（一緒に折る → 複雑な）、im-（折り込む → 含意）、du-（二つ折り → 複製）、multi-（何重にも → 増やす）、ex-（広げる → 明確な）。⚠️ supply は supplere「満たす」、comply も complere の影響を受けた語で、厳密には -ple-「満たす」系。つづりが似た語として一緒に覚える。

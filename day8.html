-cur- / -cour-跑；流动走る；流れるLatin currere / cursus

来自拉丁语 currere（跑；过去分词 cursus）。oc-（跑向 → 发生）、re-（跑回来 → 再发生）、con-（一起跑 → 同时发生的）、ex-（跑出去 → 短途旅行）、in-（跑进去 → 招致）。⚠️ Day 1–6 已出现的 currency、courier 也同源；cure（治疗）来自 cura“照料”，不同源。ラテン語 currere（走る、過去分詞 cursus）から。oc-（〜へ走る → 起こる）、re-（走り戻る → 再発する）、con-（共に走る → 同時の）、ex-（外へ走る → 小旅行）、in-（中へ走る → 招く）。⚠️ 既出の currency・courier も同源。cure（治療）は cura「世話」由来で別。

-sist- / -st- / -stit-站；立立つ；立たせるLatin stare / sistere / statuere

来自拉丁语 stare（站）、sistere（使站立）、statuere（设立）。as-（站在旁边 → 帮助）、con-（站在一起 → 一贯的）、per-（一直站着 → 坚持）、re-（反着站 → 抵抗）、sub-（站在下面 → 代替）、in-（立起来 → 机构）。⚠️ 已用过的 estate、status 也属此家族；但 assistant 与 assist 同源，history 则无关。ラテン語 stare（立つ）、sistere（立たせる）、statuere（設ける）から。as-（そばに立つ → 助ける）、con-（共に立つ → 一貫した）、per-（立ち続ける → 固執する）、re-（逆らって立つ → 抵抗する）、sub-（下に立てる → 代わりにする）、in-（立てる → 機関）。

-spir-呼吸息をするLatin spirare

来自拉丁语 spirare（呼吸）和 spiritus（气息、精神）。in-（吸进 → 激励）、a-（朝…呼吸 → 渴望）、per-（透过皮肤呼出 → 出汗）、tran-（透出 → 被得知、发生）。⚠️ expire（到期，“呼出最后一口气”）已在前面学过；spire（尖塔）不同源。ラテン語 spirare（息をする）と spiritus（息・精神）から。in-（吹き込む → 鼓舞する）、a-（〜へ息をする → 熱望する）、per-（皮膚から出す → 汗をかく）、tran-（にじみ出る → 明らかになる）。⚠️ expire（期限切れ）は既出。spire（尖塔）は別語源。

-mov- / -mot- / -mob-移动動く；動かすLatin movere / motus / mobilis

来自拉丁语 movere（移动；过去分词 motus；形容词 mobilis）。pro-（向前推动 → 促进、促销）、re-（移开 → 去除）、e-（向外动 → 情绪）、de-（向下动 → 降职）。⚠️ moment（瞬间）也同源（movimentum“移动的一刹那”）；但 motel 是 motor + hotel 的合成词。ラテン語 movere（動かす、過去分詞 motus、形容詞 mobilis）から。pro-（前へ動かす → 促進・販促）、re-（取り除く）、e-（外へ動く → 感情）、de-（下へ動かす → 降格）。⚠️ moment も同源。motel は motor＋hotel の合成語。

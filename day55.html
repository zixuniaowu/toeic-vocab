💡 后面只有名词短语 snowy weather → 介词短语 In the event of（万一）後ろは名詞句 snowy weather だけ → 前置詞句 In the event of（万一…の場合）

-sist- / -sta-站立立つLatin sistere / stare

来自拉丁语 sistere / stare（站立）。一直站着 → persist；站出来对抗 → resist；站到旁边帮忙 → assist；稳固 → stable；建立 → establish；不变 → constant。⚠️ stagnate 来自 stagnum（池塘），不是此词根。ラテン語 sistere / stare（立つ）から。最後まで立つ → persist；逆らう → resist；そばで助ける → assist；安定 → stable；設立 → establish；一定 → constant。stagnate は stagnum（池）由来で別源。

-struct- / -stru-堆建；建造積み上げる；建てるLatin struere

来自拉丁语 struere（堆起、建造）。建设 → construction；阻塞 → obstruction；破坏 → destructive；上 / 下部结构 → superstructure / substructure。ラテン語 struere（積む・建てる）から。建設 → construction；妨害 → obstruction；破壊的 → destructive；上部・下部構造 → superstructure / substructure。

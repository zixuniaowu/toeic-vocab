-scrib- / -script-写書くLatin scribere

来自拉丁语 scribere（写；过去分词 scriptus）。前缀决定“怎么写 / 写到哪儿”：de-（写下细节 → 描述）、pre-（预先写 → 开处方／规定）、trans-（抄写过去 → 誊本）、post-（写在后面 → 附言）、a-（写到某人身上 → 归因）。名词常为 -scription / -script。ラテン語 scribere（書く、過去分詞 scriptus）から。接頭辞が「どう書くか」を決める：de-（詳しく書く → 記述する）、pre-（前もって書く → 処方する／定める）、trans-（書き写す → 書き起こし）、post-（後に書く → 追伸）、a-（書きつける → 帰する）。名詞は -scription / -script が多い。

describe描述説明するprescribe开（药方）処方するtranscript誊本書き起こしmanuscript手稿原稿postscript附言追伸
-struct- / -stru-建造；堆积建てる；積み上げるLatin struere

来自拉丁语 struere（堆积、建造；过去分词 structus）。前缀：con-（一起建 → 建造）、in-（往里建／教导结构 → 指导）、ob-（挡住建造 → 妨碍）、re-（重新建 → 重建）、de-（拆掉结构 → 破坏）。名词多为 -struction / -structure。⚠️ industry、instrument 看起来像但不同源，勿硬拆。ラテン語 struere（積み上げる・建てる、過去分詞 structus）から。接頭辞：con-（共に建てる → 建設する）、in-（中に組み立てる／教える → 指導する）、ob-（妨げて建てる → 妨害する）、re-（再び建てる → 再建する）、de-（構造を壊す → 破壊）。名詞は -struction / -structure。⚠️ industry や instrument は見た目が似ても別語源。

-fer-携带；带来運ぶ；もたらすLatin ferre

来自拉丁语 ferre（携带、带来）。前缀决定“带到哪儿 / 怎么带”：re-（带回 → 提及／参考）、pre-（带到前面 → 更喜欢）、con-（带到一起 → 商议／授予）、de-（往后带 → 推迟）、inter-（带到中间 → 干涉）。名词常为 -ference / -ferral。⚠️ fertile、ferry 同源但业务场景较少；offer 虽同源，日常已固化，本课不单列。ラテン語 ferre（運ぶ）から。接頭辞：re-（戻すように運ぶ → 言及する／参照する）、pre-（前に運ぶ → 好む）、con-（共に運ぶ → 協議する／授与する）、de-（先送りに運ぶ → 延期する）、inter-（間に入って運ぶ → 干渉する）。名詞は -ference / -ferral。

refer提到言及するprefer更喜欢好むconfer商议協議するdefer推迟延期するinference推断推論
-tract-拉；抽引く；引き出すLatin trahere / tractus

来自拉丁语 trahere（拉；过去分词 tractus）。前缀：ex-（拉出来 → 提取）、dis-（拉开注意力 → 分心）、re-（拉回去 → 撤回）、pro-（向前拉长 → 拖延的）、abs-（拉开 → 摘要／抽象）、con-（一起拉 → 承包商／合同相关）。⚠️ attract（ad+tract）同源但本站尽量避开播客已讲词；contract 名词／动词重音不同，见 contractor 相关 tip。ラテン語 trahere（引く、過去分詞 tractus）から。接頭辞：ex-（引き出す → 抽出する）、dis-（注意を引き離す → 気をそらす）、re-（引き戻す → 撤回する）、pro-（長く引き延ばす → 長引いた）、abs-（引き離す → 要約／抽象）、con-（共に引く → 請負業者）。

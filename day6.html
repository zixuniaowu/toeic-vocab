-vert- / -vers-转；转向回す；向きを変えるLatin vertere / versus

来自拉丁语 vertere（转；过去分词 versus）。前缀：con-（彻底转 → 转换）、di-（转开 → 改道／多样）、re-（转回 → 颠倒、撤销）、ad-（转向对着 → 不利的）、in- + ad-（没把注意力转过来 → 不小心地）。versatile 来自 versare“反复转动”。⚠️ advertise（Day 2）也同源；但 verify（核实）来自 verus“真实的”，不同源。ラテン語 vertere（回す、過去分詞 versus）から。接頭辞：con-（すっかり回す → 転換）、di-（わきへ向ける → 迂回・多様）、re-（後ろへ回す → 逆転・取り消し）、ad-（向かい合う → 不利な）、in-＋ad-（注意を向けない → うっかり）。versatile は versare「くるくる回す」から。⚠️ advertise（Day 2）も同源だが、verify は verus「真の」由来で別語源。

来自拉丁语 rumpere（打破；过去分词 ruptus）。前缀：inter-（从中间断开 → 打断）、dis-（打散 → 扰乱）、ab-（断开离去 → 突然的）、cor-（彻底打坏 → 损坏、腐败）。bankrupt 来自意大利语 banca rotta“破了的长凳”，英语拼写受 ruptus 影响。小知识：route（路线）也来自拉丁语 rupta (via)“开辟出来的路”。ラテン語 rumpere（壊す、過去分詞 ruptus）から。接頭辞：inter-（間で断つ → 中断）、dis-（ばらばらに → 混乱させる）、ab-（断ち切る → 突然の）、cor-（すっかり壊す → 破損・腐敗）。bankrupt はイタリア語 banca rotta「壊れた台」から。豆知識：route（経路）もラテン語 rupta (via)「切り開かれた道」から。

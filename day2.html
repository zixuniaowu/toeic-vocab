-dict- / -dic-说；宣告言う；述べるLatin dicere / dictare

来自拉丁语 dicere（说）和 dictare（口述、命令）。前缀决定“怎么说”：pre-（预先说 → 预测）、contra-（对着说 → 反驳）、in-（指向着说 → 表明）。名词常变成 -diction / -dict：predict → prediction，verdict（真实说出的话 → 裁决）。ラテン語 dicere（言う）と dictare（口述する・命じる）から。接頭辞が「どう言うか」を決める：pre-（前もって言う → 予測）、contra-（反対に言う → 反論）、in-（指し示すように言う → 示す）。名詞は -diction / -dict になりやすい：predict → prediction、verdict（真実を述べたもの → 評決）。

-duc- / -duct-引导；带领導く；連れて行くLatin ducere

来自拉丁语 ducere（引导、带领）。前缀决定“往哪儿带”：re-（带回去 → 减少）、in-（带进来 → 介绍／诱导）、pro-（向前带 → 生产）、con-（一起带 → 引导／行为）。名词多为 -duction / -duct。ラテン語 ducere（導く）から。接頭辞が「どこへ導くか」を決める：re-（戻す → 減らす）、in-（中へ導く → 紹介する／誘発する）、pro-（前へ導く → 生産する）、con-（一緒に導く → 指揮する／行動）。名詞は -duction / -duct が多い。

-ject-投；扔投げるLatin jacere / jactus

来自拉丁语 jacere（投、扔；过去分词 jactus）。前缀决定“往哪儿扔”：re-（扔回去 → 拒绝）、pro-（向前扔 → 项目／投射）、in-（扔进去 → 注射）、e-（扔出去 → 弹出）、ob-（对着扔 → 反对／客观）。⚠️ project、subject、object、conduct 这类词名词与动词重音不同，见各词 tip。ラテン語 jacere（投げる、過去分詞 jactus）から。接頭辞が「どこへ投げるか」を決める：re-（投げ返す → 拒否）、pro-（前へ投げる → 計画／投影）、in-（中へ投げる → 注入）、e-（外へ投げる → 取り出す）、ob-（向かって投げる → 反対／客観）。⚠️ project などは名詞と動詞で強勢が違う（各語の tip を参照）。

-ced- / -ceed- / -cess-走；前进；让步進む；譲るLatin cedere

来自拉丁语 cedere（走、前进、让步）。拼写有三种：-ced-（precede）、-ceed-（仅 proceed / exceed / succeed 三个常用动词）、-cess-（名词 access / recession / successor）。前缀：pre-（走在前面）、ex-（走出边界 → 超过）、suc-（走到下面／接着 → 继任）、re-（往回走 → 衰退）。ラテン語 cedere（進む・譲る）から。綴りは 3 種：-ced-（precede）、-ceed-（よく使う動詞は proceed / exceed / succeed の 3 語のみ）、-cess-（名詞 access / recession / successor）。接頭辞：pre-（前を進む）、ex-（外へ出て超える）、suc-（続いて進む → 後継）、re-（戻るように進む → 後退・不況）。

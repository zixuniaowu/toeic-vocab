-cre- / -cresc- / -creat-生长；创造育つ；生み出すLatin crescere, creare

拉丁语 crescere 意为“生长、变大”：in- + crescere → increase（增加，“长进去”），de- + crescere → decrease（减少，“往下长”），incrementum → increment（增量）。同族还有 crescent（新月，“正在长大的月亮”）和 concrete（混凝土，“长在一起”）。与之同源的 creare（使产生、创造）→ create / creative / creativity，re- + creare → recreation（“重新造出精力”→ 消遣），recreational（休闲的）。⚠️ credit / credible 来自 credere“相信”，与“生长”无关；increase 和 decrease 作名词时重音前移（ˈɪnkris / ˈdikris）。ラテン語 crescere は「育つ・大きくなる」。in-＋crescere → increase（増える）、de-＋crescere → decrease（減る、「下へ育つ」）、incrementum → increment（増分）。仲間に crescent（三日月＝「満ちていく月」）、concrete（コンクリート＝「一緒に育ったもの」）。同源の creare（生み出す）→ create／creative／creativity、re-＋creare → recreation（「力を作り直す」→ 気晴らし）、recreational（レクリエーションの）。⚠️ credit／credible は credere「信じる」由来で「育つ」とは無関係。increase・decrease は名詞だと強勢が前に移る（ˈɪnkris／ˈdikris）。

-equ- / -equi-相等；平等しい；平らなLatin aequus

来自拉丁语 aequus（平的、相等的）。aequalis → equal（相等的）/ equality（平等）；ad- + aequare“使相等”→ adequate（“和要求相等”→ 足够的），in- 否定 → inadequate（不足的）；aequitas → equitable（公平的）；aequatio → equation（等式；平衡因素）；aequi- + libra“天平”→ equilibrium（平衡）；aequare → equate（等同看待）。前几天学过的 equivalent（相等的）、equity（公平；股权）也属此族。⚠️ equip（装备）一般认为来自古诺尔斯语“装备船只”，equine（马的）来自 equus“马”，都与“相等”无关。ラテン語 aequus（平らな・等しい）から。aequalis → equal（等しい）／equality（平等）。ad-＋aequare「等しくする」→ adequate（「要求に等しい」→ 十分な）、否定の in- で inadequate（不十分な）。aequitas → equitable（公平な）、aequatio → equation（方程式・等式）、aequi-＋libra「天秤」→ equilibrium（均衡）、aequare → equate（同一視する）。既習の equivalent（同等の）、equity（公平・株主資本）も同じ仲間。⚠️ equip（装備する）は古ノルド語「船を装備する」由来とされ、equine（馬の）は equus「馬」由来で、どちらも「等しい」とは無関係。

-simil- / -simul- / -sembl-相似；一起似ている；一緒にLatin similis, simul

拉丁语 similis（相似的）和 simul（一起、同时）是近亲。similis → similar / similarity；simulare“做得相像、模仿”→ simulate（模拟）/ simulation（模拟）。经古法语变形为 sembl：ad- + simul → assemble（“聚到一起”→ 组装；集合）/ assembly（组装；集会），re- + sembler“相像”→ resemble（像）/ resemblance（相似之处）。前面学过的 simultaneously（同时）也来自 simul。⚠️ assemble 与 assess（评估，ad + sedere“坐”）字形接近但不同源；resemble 后面直接接宾语，不说 resemble to / with。ラテン語 similis（似ている）と simul（一緒に・同時に）は近い親戚。similis → similar／similarity、simulare「似せる・まねる」→ simulate（模擬する）／simulation（シミュレーション）。古フランス語で sembl に変形：ad-＋simul → assemble（「一か所に集める」→ 組み立てる・集まる）／assembly（組み立て・集会）、re-＋sembler「似る」→ resemble（似ている）／resemblance（類似点）。既習の simultaneously（同時に）も simul 由来。⚠️ assemble と assess（評価する、ad＋sedere「座る」）は形が似ているが別語源。resemble は他動詞で、resemble to / with とは言わない。

-hab- / -hib-拥有；拿住；居住持つ；保つ；住むLatin habere, habitare

拉丁语 habere（拥有、拿住），反复形 habitare（住，“一直待着”）。habitus“状态、习性”→ habit（习惯）/ habitual（习惯性的）；in- + habitare → inhabit（居住于）/ inhabitant（居民）。前缀后 habere 弱化为 hib：ex- + habere“拿出来给人看”→ exhibit（展示；展品），in- + habere“往回拿住”→ inhibit（抑制），pro- + habere“挡在前面”→ prohibition（禁止）。habilis“容易拿住的 → 能干的”→ rehabilitate（使恢复；翻修），ability 也是这一家。⚠️ hibernate（冬眠）来自 hibernus“冬天的”，与 hib“拿”无关。ラテン語 habere（持つ・保つ）、その反復形 habitare（住む＝「ずっとそこにいる」）。habitus「状態・習性」→ habit（習慣）／habitual（習慣的な）、in-＋habitare → inhabit（住む）／inhabitant（住民）。接頭辞のあとで habere は hib に弱まる：ex-＋habere「外に出して見せる」→ exhibit（展示する・展示品）、in-＋habere「押しとどめる」→ inhibit（抑制する）、pro-＋habere「前で止める」→ prohibition（禁止）。habilis「扱いやすい → 有能な」→ rehabilitate（回復させる・改修する）。ability も同じ一族。⚠️ hibernate（冬眠する）は hibernus「冬の」由来で、hib「持つ」とは無関係。

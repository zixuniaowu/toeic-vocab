-spect-看見るLatin specere / spectare

来自拉丁语 specere（看）。前缀决定“往哪儿看”：pro-（向前看 → 潜在的）、in-（往里看 → 检查）、re-（回头看 → 关于、尊重）。变体 -spic-：suspicious（可疑的）。ラテン語 specere（見る）から。接頭辞が「どこを見るか」を決める：pro-（前を見る → 見込みのある）、in-（中を見る → 検査する）、re-（振り返って見る → 〜に関して・尊敬）。変化形 -spic-：suspicious（疑わしい）。

-tain- / -ten- / -tin-握住；保持つかむ；保つLatin tenere

来自拉丁语 tenere（握住）。动词多为 -tain，名词、形容词常变成 -ten- / -tin-：retain → retention，contain → continuous。⚠️ 陷阱：attain 来自 tangere（触碰），tentative 来自 tentare（尝试），都不属于这个词根。ラテン語 tenere（つかむ）から。動詞は -tain、名詞・形容詞では -ten- / -tin- になりやすい：retain → retention、contain → continuous。⚠️ 罠：attain は tangere（触れる）、tentative は tentare（試みる）由来で、この語根ではない。

-mit- / -miss-送送るLatin mittere, missus

来自拉丁语 mittere（送；过去分词 missus）。动词用 -mit，名词用 -mission：admit → admission，transmit → transmission，omit → omission，emit → emission。ラテン語 mittere（送る、過去分詞 missus）から。動詞は -mit、名詞は -mission：admit → admission、transmit → transmission、omit → omission、emit → emission。

-port-搬运；携带運ぶLatin portare

来自拉丁语 portare（搬运、携带）：ex-（运出去 → 出口）、trans-（运过去 → 运输）、re-（带回来 → 报告）。⚠️ 陷阱：opportunity 来自 portus（港口），portion 来自 portio（份额），都不是“搬运”。ラテン語 portare（運ぶ）から：ex-（運び出す → 輸出）、trans-（向こうへ運ぶ → 輸送）、re-（持ち帰る → 報告）。⚠️ 罠：opportunity は portus（港）、portion は portio（分け前）由来で、「運ぶ」ではない。

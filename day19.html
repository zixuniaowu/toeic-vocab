-mod-尺度；方式尺度；やり方Latin modus

-jus- / -jur- / -jud-法；正当法；正しいLatin jus, juris; justus; judex

来自拉丁语 jus（属格 juris：法、权利），形容词 justus“正当的”。justus + facere → justify“使正当 → 证明合理”，justification、justifiable；justitia → justice。in-“不” + juria → injury“不正当的事 → 伤害”。jurare“（依法）发誓” → jury“陪审团、评审团”、juror。jus + dicere“说”（Day 2 的 dict）→ judex“法官”、judicium“判断” → judge、judgment、prejudice“预先判断 → 偏见”。本站学过的 jurisdiction（管辖权）也属于这个家族。⚠️ adjust 来自古法语 ajouster，源于拉丁语 juxta“靠近”，只是后来被联想成 just，不同源。ラテン語 jus（属格 juris：法・権利）、形容詞 justus「正しい」から。justus + facere → justify「正しいとする → 正当化する」、justification、justifiable。justitia → justice。in-「〜でない」+ juria → injury「不正なこと → 害・けが」。jurare「（法にかけて）誓う」→ jury「陪審・審査員団」、juror。jus + dicere「言う」（Day 2 の dict）→ judex「裁判官」、judicium「判断」→ judge、judgment、prejudice「前もっての判断 → 偏見」。既習の jurisdiction（管轄）も同じ仲間。⚠️ adjust は古フランス語 ajouster（ラテン語 juxta「近くに」）から来ており、後から just と結びつけられただけで別語源。

-fus- / -fund-倒；浇；熔化注ぐ；溶かすLatin fundere, fusus

来自拉丁语 fundere（倒、浇、熔化），过去分词 fusus。re-“往回” → refund“倒回去 → 退款”（本站已学），一般认为 refuse“推回去 → 拒绝”、refusal 也来自 refundere；con-“一起” → confuse、confusion“倒在一起 → 混乱”；in-“向内” → infuse“注入”；dis-（dif-）“四散” → diffuse“扩散”；pro-“向外” → profuse(ly)“大量涌出”；fusion“熔化 → 融合”。⚠️ fund（资金）、fundamental（基本的）来自 fundus“底部”，与 fundere 不同源——refund 看起来像 re + fund，其实属于 fundere。⚠️ defuse 里的 fuse“引信”来自 fusus“纺锤”，也不是这个词根。ラテン語 fundere（注ぐ・溶かす）、過去分詞 fusus から。re-「戻して」→ refund「注ぎ返す → 払い戻す」（既習）。refuse「突き返す → 断る」・refusal も一般に refundere 由来とされる。con-「共に」→ confuse・confusion「一緒に注ぐ → 混乱」。in-「中へ」→ infuse「注ぎ込む」。dis-（dif-）「四方へ」→ diffuse「拡散する」。pro-「外へ」→ profuse(ly)「あふれ出るほど」。fusion「溶けること → 融合」。⚠️ fund（資金）・fundamental（基本的な）は fundus「底」から来ており、fundere とは別語源。refund は re + fund に見えるが実は fundere の仲間。⚠️ defuse の fuse「信管」は fusus「紡錘」から来ており、この語根ではない。

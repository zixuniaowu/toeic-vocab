-vis- / -vid-看；看见見る；見えるLatin videre / visus

来自拉丁语 videre（看；过去分词 visus）。变体 vis / vid / view。前缀：re-（再看 → 修订）、super-（从上往下看 → 监督）、pro-（预先看 → 提供／临时的）、ad-（向…看／告知 → 建议）、in-（看不见 → 看不见的）。evidence 来自 evidere“看清楚”。⚠️ visit 同源但本课另选高频派生；television 本义“远处看见”。ラテン語 videre（見る、過去分詞 visus）から。異形 vis / vid / view。接頭辞：re-（再び見る → 改訂する）、super-（上から見る → 監督する）、pro-（前もって見る → 提供する／暫定の）、ad-（知らせる → 助言する）、in-（見えない → 見えない）。evidence は evidere「はっきり見る」。

-sign-标记；符号；指示印；合図；示すLatin signum / signare

来自拉丁语 signum（标记）及动词 signare（做标记）。前缀：de-（往下标出 → 指定）、in-（无标记／不重要 → 无关紧要的）、as-（标给 → 指派，本站尽量避开播客已讲词）。名词常为 -signature / -ignation。⚠️ assign、resign 同源但播客已出现，本课改选其他高频形。ラテン語 signum（印）と signare（印をつける）から。接頭辞：de-（示して決める → 指定する）、in-（重要でない → 取るに足りない）。名詞は -signature / -ignation が多い。⚠️ assign・resign は同源だが本課では他語を優先。

-pend- / -pens-悬挂；衡量；支付ぶら下げる；量る；支払うLatin pendere / pensus

来自拉丁语 pendere（悬挂、衡量、支付；过去分词 pensus）。“挂着／悬而未决”→ pending；“称量后付出”→ expend / expense；“挂起暂停”→ suspend；“定期支付”→ pension。前缀：de-（依靠挂在…上 → 依赖）、im-（逼近悬挂 → 即将到来）、in- + dis-（无法省去 → 不可或缺）。⚠️ compensate / expenditure 同源，但播客已出现，本课避开。ラテン語 pendere（ぶら下げる・量る・支払う、過去分詞 pensus）から。pending は「懸案」、expend / expense は「支出」、suspend は「一時停止」、pension は「定期支払い」。接頭辞：de-（〜に依る）、im-（差し迫る）、indispensable は「欠かせない」。

-press-压；按；挤押す；圧するLatin premere / pressus

来自拉丁语 premere（压；过去分词 pressus）。前缀：ex-（压出来 → 表达／快件）、im-（压进去 → 留下印象）、su(b)-（压下去 → 压制）、de-（往下压 → 使沮丧／萧条）、com-（压在一起 → 压缩）。名词多为 -pression / -pressure。⚠️ express 作名词（特快）与动词（表达）重音不同，见词条 tip。ラテン語 premere（押す、過去分詞 pressus）から。接頭辞：ex-（押し出す → 表現する／急行）、im-（押し込む → 印象づける）、su(b)-（抑え込む → 抑圧する）、de-（押し下げる → 落ち込ませる）。名詞は -pression / -pressure。⚠️ express は名詞と動詞で強勢が異なる場合あり。

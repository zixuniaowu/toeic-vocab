-pop- / -publ-人民；公众人々；公衆Latin populus, publicus

来自拉丁语 populus（人民），形容词 publicus（公众的）与它有关。受大众欢迎 → popular / popularity；人的总数 → population；住满人 → populate / populated；人多的 → populous。公众的 → public / publicly；让公众知道 → publicize（publicity 宣传）；让公众看到的作品 → publish / publisher。⚠️ populous（人口多）≠ popular（受欢迎）；pub（酒馆）是 public house 的缩写，确实同源，但 pupil（学生）、puberty 无关。ラテン語 populus（人々）、形容詞 publicus（公の）はこれと関係がある。大衆に好まれる → popular／popularity、人の総数 → population、人が住む → populate／populated、人の多い → populous。公の → public／publicly、公に知らせる → publicize（publicity 宣伝）、公にする作品 → publish／publisher。⚠️ populous（人口の多い）≠ popular（人気のある）。pub は public house の略で同語源だが、pupil（生徒）は無関係。

-hosp- / -host-客人；主人客；もてなす主人Latin hospes, hospit-

来自拉丁语 hospes（hospit-），既指“客人”也指“招待客人的主人”。好客的 → hospitable / inhospitable；招待客人的地方 → 中世纪拉丁语 hospitale，后来分化成 hospital（医院）、hostel（旅舍）、hotel（酒店）三个词；主人 → host / hostess / co-host（联合主办）。记忆：hospital、hostel、hotel 原本都是“接待人的地方”。⚠️ hostile（敌对的）和 a host of（大量）来自 hostis“陌生人 → 敌人”，意思已经完全不同，不要混淆。ラテン語 hospes（hospit-）は「客」と「客をもてなす主人」の両方を指す。もてなしのよい → hospitable／inhospitable。客を迎える場所 → 中世ラテン語 hospitale が hospital（病院）、hostel（宿）、hotel（ホテル）の 3 語に分かれた。主人 → host／hostess／co-host（共催）。「hospital・hostel・hotel はもとは全部“人を迎える場所”」と覚えよう。⚠️ hostile（敵意のある）や a host of（多数の）は hostis「よそ者 → 敵」由来で意味が全く違う。

-mens- / -meter-测量測るLatin metiri, mensus; Greek metron

拉丁语 metiri（过去分词 mensus）“测量”和希腊语 metron“尺度”是同一个古老词根的亲戚。拉丁系：dis-“完全”→ dimension（尺寸）；im-“不”→ immense（量不出 → 巨大的）/ immensely；com-“共同”→ commensurate（同一尺度 → 相称的）；mensura → measure → measurable。希腊系：peri-“周围”→ perimeter（周长）；dia-“穿过”→ diameter（直径）；para-“旁边”→ parameter（参数）。已学过的 meter、measurement 也属这一族。⚠️ mental（精神的）、mention 来自 mens“心智”，与“测量”无关。ラテン語 metiri（過去分詞 mensus）「測る」とギリシャ語 metron「尺度」は同じ古い語根の親戚。ラテン系：dis-「すっかり」→ dimension（寸法）、im-「不」→ immense（測れない → 巨大な）／immensely、com-「共に」→ commensurate（同じ尺度 → 見合った）、mensura → measure → measurable。ギリシャ系：peri-「周り」→ perimeter（周囲）、dia-「横切って」→ diameter（直径）、para-「そば」→ parameter（条件）。既習の meter、measurement も同じ仲間。⚠️ mental、mention は mens「心」由来で「測る」とは無関係。

-bene- / -bon-好；善よく；よいLatin bene, bonus

拉丁语副词 bene“好地”和形容词 bonus“好的”。bene + facere“做”→ benefit（好处）/ beneficial（有益的）；bene + velle“愿意”→ benevolent（仁慈的）；bene + gignere“生”→ benign（良性的、温和的，g 不发音）。bonus 系：bona fide（以诚信 → 真正的）；bonitas → 古法语 bonte → bounty（赏金）/ bountiful（丰富的）。已学过的 bonus、beneficiary、benefactor 也属这一族。反义词根 mal-“坏”：malfunction（故障）。⚠️ bench（长椅）、bend 与 bene 无关。ラテン語の副詞 bene「よく」と形容詞 bonus「よい」。bene＋facere「する」→ benefit（利点）／beneficial（有益な）、bene＋velle「望む」→ benevolent（慈悲深い）、bene＋gignere「生む」→ benign（良性の・穏やかな、g は発音しない）。bonus 系：bona fide（誠意をもって → 本物の）、bonitas → 古フランス語 bonte → bounty（報奨金）／bountiful（豊富な）。既習の bonus、beneficiary、benefactor も仲間。反対は mal-「悪い」：malfunction（故障）。⚠️ bench や bend は無関係。

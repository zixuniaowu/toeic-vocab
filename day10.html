-manu- / -man-手手Latin manus

来自拉丁语 manus（手）。manual“手的 → 手册／手动的”，manufacture“用手做 → 制造”，manage“用手操控 → 管理”，manipulate“用手操作”，maneuver“用手操作 → 机动”，command 经 mandare（manus + dare“交给”）同源。⚠️ maintain（Day 1）也含 man-，但来自 manu tenere“用手握住”。ラテン語 manus（手）から。manual「手の → 説明書・手動」、manufacture「手で作る → 製造」、manage「手で扱う → 管理」、manipulate「手で操る」、maneuver「手で動かす → 機動」。command は mandare（manus＋dare）経由で同源。⚠️ maintain（Day 1）も man- を含む（manu tenere）。

-val- / -vail-价值；强壮価値がある；強いLatin valere / valor

来自拉丁语 valere（强壮、有价值）和 valor（价值）。valuable“有价值的”，evaluate“估出价值”，available“能用得上的”，prevail“更强壮 → 占上风”，equivalent“价值相等的”，validate“使有效”。⚠️ invaluable = 贵到无法估价（≠ worthless）。ラテン語 valere（強い・価値がある）と valor（価値）から。valuable「価値のある」、evaluate「価値を見積もる」、available「利用できる」、prevail「より強い → 優勢」、equivalent「価値が等しい」、validate「有効にする」。⚠️ invaluable＝値踏みできないほど貴重（worthless ではない）。

-dur-持久；坚硬続く；硬いLatin durare / durus

来自拉丁语 durare（持久）和 durus（硬的）。durable“耐用的”，endure“使坚硬 → 忍受”，duration“持续时间”，duress“严厉 → 胁迫”。during 是 dure 的现在分词形式。ラテン語 durare（続く）と durus（硬い）から。durable「耐久性のある」、endure「耐える」、duration「期間」、duress「厳しさ → 脅迫」。during は dure の現在分詞形。

-flu- / -flux-流流れるLatin fluere / fluxus

来自拉丁语 fluere（流；过去分词 fluxus）。fluent“流畅的”，influence“流入 → 影响”，fluctuate“像波浪流动 → 波动”，affluent“流入丰富的 → 富裕的”，influx“流入”，superfluous“溢出来的 → 多余的”。ラテン語 fluere（流れる、過去分詞 fluxus）から。fluent「流暢な」、influence「流れ込む → 影響」、fluctuate「波のように動く → 変動」、affluent「流れ込む → 裕福な」、influx「流入」、superfluous「あふれ出た → 余分な」。

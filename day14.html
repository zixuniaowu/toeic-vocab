来自拉丁语 vocare（叫、呼唤）和 vox（声音）。ad-（叫来帮忙 → 拥护者、提倡）、advocacy“倡导”、re-（叫回 → 撤销）、irrevocable“叫不回的 → 不可撤销的”、pro-（叫出来 → 激起）、in-（呼唤来相助 → 援引条款）、vocational“被召唤的工作 → 职业的”、vocal“有声的 → 直言的”。voice、vocabulary 也同源。⚠️ vocation（职业）≠ vacation（假期，来自 vacare“空”）；avocado 与 advocate 毫无关系。ラテン語 vocare（呼ぶ）と vox（声）から。ad-（助けに呼ぶ → 擁護者・提唱する）、advocacy「擁護」、re-（呼び戻す → 取り消す）、irrevocable「取り消せない」、pro-（呼び出す → 引き起こす）、in-（呼び求める → 条項を発動する）、vocational「職業の」、vocal「声高な」。voice・vocabulary も同源。⚠️ vocation（職業）≠ vacation（休暇、vacare「空」）。avocado は advocate と無関係。

-tribut-给予；分配与える；割り当てるLatin tribuere

来自拉丁语 tribuere（分配、给予），过去分词 tributus；本义可能是“分给各部落（tribus）”。dis-（分开给 → 分发、分销）、distributor“经销商”、distribution“分销、配送”、at-（归给 → 归因于）、attributable“可归因的”、con-（一起拿出 → 贡献）、contributor“贡献者、撰稿人”、tribute“交付之物 → 致敬”。⚠️ attribute 作动词重音在第二音节，作名词重音在第一音节。ラテン語 tribuere（割り当てる・与える、過去分詞 tributus）から。原義は「部族（tribus）に割り当てる」とされる。dis-（分けて与える → 配布する・流通させる）、distributor「販売代理店」、distribution「流通」、at-（帰する → 〜のおかげとする）、attributable「〜に起因する」、con-（一緒に出す → 貢献する）、contributor「貢献者・寄稿者」、tribute「納めるもの → 賛辞」。⚠️ attribute は動詞なら第2音節、名詞なら第1音節にアクセント。

-put-思考；计算考える；数えるLatin putare

来自拉丁语 putare（原义“修剪、清理”，引申为“盘算、思考、计算”）。com-（一起算 → 计算）、computation“计算”、dis-（分开思考 → 争论）、indisputable“无可争辩的”、re-（反复思量 → 名声）、reputable“声誉好的”、disreputable“名声差的”、de-（认定、指派 → 副职、代理人）。⚠️ 英语的 put（放）、input、output 是本族词，与 putare 不同源。ラテン語 putare（原義「刈り込む・整える」→「見積もる・考える・数える」）から。com-（合わせて数える → 計算する）、computation「計算」、dis-（分けて考える → 論争）、indisputable「議論の余地のない」、re-（繰り返し考える → 評判）、reputable「評判の良い」、disreputable「評判の悪い」、de-（割り当てる → 代理人・副〜）。⚠️ 英語の put（置く）・input・output は英語本来の語で別語源。

-mand- / -mend-托付；命令委ねる；命じるLatin mandare

来自拉丁语 mandare（托付、命令），常解释为 manus（手，见 Day 10 -manu-）+ dare（给）“交到手里”；在 commendare 中变为 -mend-。mandate“授权、强制规定”、mandatory“强制的”、de-（托付 → 要求、需求）、demanding“要求高的”、com-（托付 → 称赞、推荐）、commendable“值得称赞的”、commendation“表彰”、recommendation“推荐、建议”。⚠️ reprimand（训斥，来自 reprimere“压回”）和 amend / mend（修改、修补，来自 menda“缺陷”）都不同源。ラテン語 mandare（委ねる・命じる）から。manus（手、Day 10 の -manu- 参照）+ dare（与える）「手に渡す」と説明される。commendare では -mend- になる。mandate「権限・義務付ける」、mandatory「義務的な」、de-（委ねる → 要求・需要）、demanding「要求の厳しい」、com-（委ねる → 称賛する・推薦する）、commendable「称賛に値する」、commendation「表彰」、recommendation「推薦・勧告」。⚠️ reprimand（叱責、reprimere「押し戻す」）と amend / mend（修正する・直す、menda「欠陥」）は別語源。

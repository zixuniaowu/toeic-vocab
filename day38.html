🔍 今日词根🔍 今日の語根

-us- / -ut-使用使うLatin uti, usus

来自拉丁语 uti（使用）及其过去分词 usus。使用量 → usage；可使用 → usable；有效利用 → utilize；用错 → misuse / abuse；再次使用 → reusable。⚠️ usher（引座员）和 usual（通常的）不要硬套“使用”：usual 与“习惯使用”有关，usher 来自“门”，需单独记。ラテン語 uti（使う）とその過去分詞 usus から。使用量 → usage；使える → usable；活用する → utilize；誤用 → misuse／abuse；再利用 → reusable。⚠️ usher（案内係）は「門」由来で別語源。

-numer-数数Latin numerus

来自拉丁语 numerus（数）。数 → number；数量上超过 → outnumber；数字 → numeral / numeric；列举 → enumerate；数不清 → innumerable。⚠️ numerous 是“众多的”，常见于 numerous + 复数名词。ラテン語 numerus（数）から。数 → number；数で上回る → outnumber；数字 → numeral／numeric；列挙 → enumerate；数えきれない → innumerable。

-cycl-圆；环；周期円；輪；周期Greek kyklos

来自希腊语 kyklos（圆、环）。周期 → cycle / cyclical；两轮 → bicycle；有发动机的 → motorcycle；骑车的人 → cyclist；全面教育的环 → encyclopedia。⚠️ cycl 里的 c 在 cycle、cyclical 中都读 /s/，不要读成 /k/。ギリシャ語 kyklos（円・輪）から。周期 → cycle／cyclical；二輪 → bicycle；原動機付き → motorcycle；乗る人 → cyclist；百科事典 → encyclopedia。⚠️ cycl の c は /s/ と読む。

-arch-首领；统治；起初首長；支配；初めGreek archos, arkhe

来自希腊语 archos（首领、统治者）和 arkhe（起初）。主要建造者 → architecture；神圣统治 → hierarchy / hierarchical；一人统治 → monarchy；没有统治 → anarchy；起初 → archaic；官府文书 → archival。⚠️ arch 还可以是“拱门”，与此词根不同；archive 也在先前日子出现过。ギリシャ語 archos（首長・支配者）と arkhe（初め）から。棟梁 → architecture；聖なる支配 → hierarchy／hierarchical；一人の支配 → monarchy；支配なし → anarchy；古い → archaic；文書庫 → archival。⚠️ arch（アーチ）は別語。

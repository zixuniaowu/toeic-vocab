-temp- / -tempor-时间時間Latin tempus, temporis

来自拉丁语 tempus（时间）。与时间有关 → temporal（时间的；世俗的）；暂时的 → temporary / temporarily；同属一个时代 → contemporary（当代的；同时代的人）/ contemporaneous（同时发生的）；节奏、速度 → tempo；口语里“临时工”→ temp；测量冷热的“时间上的程度”引申 → temperature（温度）。⚠️ temper（脾气；回火）和 temperament（性情）来自 temperare“调和”，与“时间”不同源；template（模板）也无关。ラテン語 tempus（時間）から。時間に関する → temporal（時間の；世俗の）。一時的な → temporary／temporarily。同じ時代の → contemporary（現代の；同時代人）／contemporaneous（同時期の）。速さ・テンポ → tempo。口語で「臨時社員」→ temp。寒暖の度合い → temperature（温度）。⚠️ temper（気性；焼きを入れる）と temperament（気質）は temperare「調える」由来で「時間」とは別。template（型）も無関係。

-phon- / -phone-声音；嗓音音；声Greek phōnē

来自希腊语 phōnē（声音、嗓音）。远方的声音 → telephone（电话）；头上的扬声器 → headphone / earphones；智能电话 → smartphone；大声传声的喇叭 → megaphone；“一起发出的声音”→ symphony（交响乐；和谐）；与语音有关 → phonetic / phonetics（语音的 / 语音学）。复合时 -phone 常指“发声装置”。⚠️ -phony 也可表“某种声音状态”（cacophony 刺耳声、euphony 悦耳），但本课聚焦商务场景常用词。ギリシャ語 phōnē（音・声）から。遠い音 → telephone（電話）。頭につけるスピーカー → headphone／earphones。賢い電話 → smartphone。大きな声を伝えるラッパ → megaphone。「一緒に響く音」→ symphony（交響曲；調和）。音声に関する → phonetic／phonetics（音声の／音声学）。複合語の -phone は「音を出す装置」を指すことが多い。⚠️ -phony は「音の状態」（cacophony 不協和音、euphony 快い響き）も表すが、本課はビジネスで使う語に絞る。

-path-感受；痛苦；疾病感情；苦しみ；病気Greek pathos

来自希腊语 pathos（感受、痛苦）。共同感受 → sympathy / sympathetic / sympathize（同情；共鸣）；进入对方感受 → empathy（共情）；没有感受 → apathy（冷漠）；引人哀怜 → pathetic（可怜的；差劲的）；致病之物 → pathogen（病原体）；研究疾病 → pathology（病理学）。⚠️ path- 作“道路”时来自希腊语 pathos 的另一同源词 path（如 pathway、psychopath 的 -path 指“患者/受影响者”），词源相关但现代义项要分清：同情类 vs 疾病类。ギリシャ語 pathos（感情・苦しみ）から。共に感じる → sympathy／sympathetic／sympathize（同情；共感）。相手の感情に入る → empathy（共感）。感情がない → apathy（無関心）。哀れを誘う → pathetic（哀れな；ひどい）。病を起こすもの → pathogen（病原体）。病気を研究する学問 → pathology（病理学）。⚠️「道」の path（pathway など）や psychopath の -path「〜に侵された人」は同源だが、現代では「同情」系と「病気」系で意味が分かれる。

-brev- / -brief-短；简短短い；簡潔Latin brevis

来自拉丁语 brevis（短的）。简短的 → brief（简短的；简报）/ briefly（简短地）/ brevity（简洁）；使变短 → abbreviate（缩写）→ abbreviation（缩写形式）；装文件的短箱 → briefcase（公文包）；任务前后的简短说明 → briefing（简报会）/ debrief（任务后听取汇报）。⚠️ brief 作名词可指“案情摘要、律师委托”；in brief = 简言之。ラテン語 brevis（短い）から。短い → brief（短い；概要）／briefly（簡潔に）／brevity（簡潔さ）。短くする → abbreviate（省略する）→ abbreviation（略語）。書類を入れる短い箱 → briefcase（ブリーフケース）。作業前後の短い説明 → briefing（ブリーフィング）／debrief（事後報告を聞く）。⚠️ brief は名詞で「案件概要・依頼内容」の意味も。in brief＝要するに。

-lev-举起；减轻持ち上げる；軽くするLatin levare, levis

来自拉丁语 levare（举起、减轻）和 levis（轻的）。e-（向上举 → 提升）、al-（使变轻 → 缓解）、re-（再举起、卸下重担 → 解除、减轻）、relevant 原义“托起、相关”，加 ir- 变成“无关的”；levy“征收”来自法语 lever“举起、征集”；lever“杠杆、把手”就是“用来抬起的东西”。elevator 也同源。⚠️ level（水平）来自 libra“天平”，不同源；leaven（酵母）虽同源但不是 TOEIC 词。ラテン語 levare（持ち上げる・軽くする）と levis（軽い）から。e-（上へ持ち上げる → 高める）、al-（軽くする → 和らげる）、re-（重荷を持ち上げて下ろす → 和らげる・解放する）、relevant は「持ち上げる → 関係がある」で、ir- がつくと「無関係な」。levy「課す」はフランス語 lever「持ち上げる・徴収する」から。lever「てこ・レバー」は「持ち上げる道具」。elevator も同源。⚠️ level（水準）は libra「天秤」由来で別語源。

-cid- / -cas-落下；发生落ちる；起こるLatin cadere, casus

来自拉丁语 cadere（落下），过去分词 casus。in-（落到……上 → 事件、附带的）、co-+in-（一起落下 → 同时发生、巧合）、ac-（落到身上 → 意外的）、oc-（落在面前 → 场合、偶尔的）、casual 来自 casus“偶然落下”→ 随意的、非正式的。case、cascade 也同源。⚠️ decide、precise、concise 的 -cid-/-cis- 来自 caedere“切、杀”，和“落下”不同源；pesticide 的 -cide 也是“杀”。ラテン語 cadere（落ちる）、過去分詞 casus から。in-（…の上に落ちる → 出来事・付随的な）、co-+in-（一緒に落ちる → 同時に起こる・偶然の一致）、ac-（身に降りかかる → 偶然の）、oc-（目の前に落ちる → 機会・時折の）、casual は casus「偶然」から → 気軽な・普段着の。case・cascade も同源。⚠️ decide・precise・concise の -cid-/-cis- は caedere「切る・殺す」由来で別語源。pesticide の -cide も「殺す」。

-sum- / -sumpt-拿；取取るLatin sumere, sumptus

来自拉丁语 sumere（拿、取），过去分词 sumptus。as-（拿到自己身上 → 承担；假定）、con-（全部拿走 → 消耗、消费）、pre-（预先拿来当真 → 推测）、re-（再拿起 → 恢复、重新开始）、sumptuous 来自 sumptus“花费”→ 奢华的。名词形变成 -sumption：consumption、resumption、assumption。⚠️ sum（总和）来自 summus“最高的”，summit 也是，和“拿”不同源。ラテン語 sumere（取る）、過去分詞 sumptus から。as-（自分に取る → 引き受ける・仮定する）、con-（すっかり取る → 消費する）、pre-（前もって取る → 推定する）、re-（再び取る → 再開する）、sumptuous は sumptus「出費」から → 豪華な。名詞は -sumption：consumption・resumption・assumption。⚠️ sum（合計）は summus「最高の」由来（summit も）で別語源。

-medi-中间中間Latin medius

来自拉丁语 medius（中间的）。mediate“站在中间 → 调解”、inter-（在……之间的中间 → 中级的、中间人）、median“中间的 → 中位数、中央分隔带”、medium“中间 → 中等的；媒介”（复数 media）、mediocre“中等高度 → 平庸的”、multimedia“多种媒介”。immediate“没有中间环节 → 立即的”也同源。⚠️ medical、medicine 来自 mederi“治疗”，和 medi-“中间”不同源。ラテン語 medius（中間の）から。mediate「間に立つ → 仲裁する」、inter-（間の中ほど → 中級の・仲介者）、median「真ん中の → 中央値・中央分離帯」、medium「中間 → 中くらいの；媒体」（複数 media）、mediocre「中くらいの高さ → 平凡な」、multimedia「複数の媒体」。immediate「間に何もない → 即時の」も同源。⚠️ medical・medicine は mederi「治す」由来で別語源。

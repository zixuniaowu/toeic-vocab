-cord- / -cour-心心Latin cor, cordis

来自拉丁语 cor（属格 cordis，心）。ad- + cor → accord“心意相合 → 一致、协议”，according to、accordingly（相应地）；cordial“发自内心的 → 热情的”，cordially（诚挚地，邀请函常用）；dis- + cor → discord“心分开 → 不和”。经古法语变成 cour-：courage（勇气，古人认为勇气在心里）、encourage（使有勇气 → 鼓励）、discourage（去掉勇气 → 劝阻）。record 也来自 recordari“记在心里”。⚠️ cord（绳子）来自希腊语 khordē，与“心”无关；courier、course 的 cour 来自 currere“跑”（Day 8），也不同源。ラテン語 cor（属格 cordis、心）から。ad- + cor → accord「心が合う → 一致・協定」、according to、accordingly（それに応じて）。cordial「心からの → 友好的な」、cordially（謹んで、招待状の定番）。dis- + cor → discord「心が離れる → 不和」。古フランス語を経て cour- に：courage（勇気。勇気は心に宿ると考えられた）、encourage（勇気を与える → 励ます）、discourage（勇気を奪う → 思いとどまらせる）。record も recordari「心に留める」から。⚠️ cord（ひも）はギリシャ語 khordē 由来で「心」とは無関係。courier・course の cour はラテン語 currere「走る」（Day 8）で別語源。

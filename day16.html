-nov-新新しいLatin novus, novare

来自拉丁语 novus（新的）和 novare（使变新）。in-（使……新 → 革新、创新）、novel 原义“新的”，作形容词是“新颖的”，作名词“小说”来自意大利语 novella“新故事”；novelty“新奇、新鲜感”，novice“新手”。Day 6 学过的 renovate（翻新）也是同一词根。⚠️ November 来自 novem“九”（古罗马历的第九个月），与“新”无关；notice、notify 的 not- 来自 noscere“知道”，也不同源。ラテン語 novus（新しい）と novare（新しくする）から。in-（新しくする → 革新する）、novel は本来「新しい」で、形容詞は「斬新な」、名詞「小説」はイタリア語 novella「新しい話」から。novelty「目新しさ」、novice「初心者」。Day 6 の renovate（改装する）も同じ語根。⚠️ November は novem「9」（古代ローマ暦の 9 番目の月）由来で「新しい」とは無関係。notice・notify の not- は noscere「知る」で別語源。

-prehend- / -pris-抓住；拿つかむ；取るLatin prehendere; Old French prendre, pris

来自拉丁语 prehendere（抓住），到法语变成 prendre，过去分词 pris。com-（完全抓住 → 理解；全部抓在一起 → 全面的）、ap-（向……抓 → 理解 → 担心会发生 → 忧虑的）；法语 entreprendre“着手做”（entre 之间 + prendre 拿）→ enterprise 企业、事业，entrepreneur 创业者；comprise“包含、由……组成”来自 compris“被抓在一起”；apprentice“学徒”来自 apprendre“学习（把知识抓到手）”。surprise 也同源（从上面抓住 → 突然袭击 → 惊讶）。⚠️ price、prize、precious 来自 pretium“价格”，不同源。ラテン語 prehendere（つかむ）から。フランス語では prendre、過去分詞 pris。com-（完全につかむ → 理解する；全部をまとめてつかむ → 包括的な）、ap-（〜へ向かってつかむ → 理解する → 起こりそうで不安な）。フランス語 entreprendre「取りかかる」（entre 間 + prendre 取る）→ enterprise 企業・事業、entrepreneur 起業家。comprise「含む・〜から成る」は compris「まとめてつかまれた」から。apprentice「見習い」は apprendre「学ぶ（知識をつかむ）」から。surprise も同源（上からつかむ → 不意打ち → 驚き）。⚠️ price・prize・precious は pretium「価格」由来で別語源。

-fort-强；有力強い；力のあるLatin fortis

来自拉丁语 fortis（强壮的）。ef-（ex- 的变体，向外使力 → 努力）、com-（一起加强 → 安慰、舒适）、-ify（使强 → 加固、强化）、re- + in- + force（再给力量 → 加强、增援）；forte“长处、强项”来自法语 fort“强”。force、enforce（Day 2）、fort（要塞）、fortress 也同源。⚠️ fortune（运气）来自 fors“偶然、运气”，不同源；forth、forward 是本族词，也无关。ラテン語 fortis（強い）から。ef-（ex- の異形、外へ力を出す → 努力）、com-（共に強める → 慰め・快適さ）、-ify（強くする → 強化する）、re- + in- + force（再び力を与える → 補強する）。forte「長所・得意分野」はフランス語 fort「強い」から。force、enforce（Day 2）、fort（要塞）、fortress も同源。⚠️ fortune（運）は fors「偶然」由来で別語源。forth・forward は本来の英語で無関係。

-cern- / -cert-分辨；确定見分ける；確かなLatin cernere, certus

来自拉丁语 cernere（筛分、分辨、决定），过去分词 certus“已确定的 → 确实的”。dis-（分开来看 → 辨别）、con-（混在一起筛 → 与……有关 → concerning“关于”）；-ify（使确定 → 证明、认证）、certificate“证书”、ascertain（a- = ad-“向”+ certain → 查明、确认）、certainty / uncertainty“确定性 / 不确定性”。secret、discreet、decree 也同源。⚠️ concert（音乐会）来自意大利语 concertare，词源有争议，不要硬套；cereal、cerebral 也无关。ラテン語 cernere（ふるい分ける・見分ける・決める）、過去分詞 certus「決まった → 確かな」から。dis-（分けて見る → 識別する）、con-（混ぜてふるう → 関係する → concerning「〜に関して」）。-ify（確かにする → 証明する・認定する）、certificate「証明書」、ascertain（a- = ad-「〜へ」+ certain → 確かめる）、certainty / uncertainty「確実性・不確実性」。secret、discreet、decree も同源。⚠️ concert（コンサート）はイタリア語 concertare 由来で語源に諸説あり、当てはめないこと。cereal・cerebral も無関係。

-centr- / -center-中心中心Latin centrum, Greek kentron

来自拉丁语 centrum（中心），源自希腊语 kentron“圆规的尖脚”——画圆时扎在中间的那一点。中心的 → central / centrally；使集中 → centralize，加 de-“相反”→ decentralize（分散）；con-“一起”→ concentration（集中、专注）；ec-“离开”→ eccentric（偏离中心 → 古怪的）；epi-“在上面”→ epicenter（震中 → 中心地）；center + piece → centerpiece（重头戏）。⚠️ cent（分、百）来自 centum“一百”，century、percent 都与“中心”无关。ラテン語 centrum（中心）、さらにギリシャ語 kentron「コンパスの針」——円を描くとき真ん中に刺す一点から。中心の → central／centrally。集中させる → centralize、de-「逆」→ decentralize（分散させる）。con-「共に」→ concentration（集中）、ec-「外へ」→ eccentric（中心から外れた → 風変わりな）、epi-「上に」→ epicenter（震央 → 中心地）、center＋piece → centerpiece（目玉）。⚠️ cent（セント）や century、percent は centum「100」由来で「中心」とは無関係。

-grav- / -griev-重重いLatin gravis

来自拉丁语 gravis（重的）。重量、分量 → gravity（重力；严重性）；重 → 严重 → grave / gravely（严重地）；像被重力吸过去 → gravitate（倾向于）；ad-“向”+ 加重 → aggravate（使恶化）。经古法语 grever“使负重、使痛苦”变形为 griev：grievance（不满、申诉）、aggrieved（受损害的）。记忆：心里“重”了就有 grievance。⚠️ 名词 grave（坟墓）、engrave（雕刻）来自古英语 grafan“挖”，与 gravis 无关；gravy（肉汁）也无关。ラテン語 gravis（重い）から。重さ → gravity（重力；重大さ）、重い → 深刻な → grave／gravely、重力に引かれるように → gravitate（引き寄せられる）、ad-「〜へ」＋重くする → aggravate（悪化させる）。古フランス語 grever「重荷を負わせる・苦しめる」を経て griev の形に：grievance（不満・苦情）、aggrieved（被害を受けた）。「心が重い → grievance」と覚えよう。⚠️ 名詞 grave（墓）や engrave（彫る）は古英語 grafan「掘る」由来で無関係。gravy（肉汁）も無関係。

-luc- / -lumin- / -lustr-光光Latin lux (lucis), lumen, lustrare

来自拉丁语 lux（光，词干 luc-）、lucere“发光”和 lumen“光”（词干 lumin-）；lustrare“照亮”也与之相关。发光、明亮 → lucid（清楚易懂的）/ luminous（发光的）；e-“出”→ elucidate（阐明）；trans-“穿过”→ translucent（半透明）；in-“照进”→ illuminate / illumination（照亮、灯饰）；illustrare“照亮 → 阐明”→ illustrate（说明）/ illustrious（显赫的）。记忆：把光照进去 = 让人看清楚。⚠️ lumber（木材）、lucky（幸运的）与“光”无关。ラテン語 lux（光、語幹 luc-）、lucere「輝く」、lumen「光」（語幹 lumin-）から。lustrare「照らす」も関連する。明るい → lucid（明快な）／luminous（光る）、e-「外へ」→ elucidate（解明する）、trans-「通して」→ translucent（半透明の）、in-「中へ」→ illuminate／illumination（照らす・イルミネーション）、illustrare「照らす → 明らかにする」→ illustrate（説明する）／illustrious（名高い）。「光を当てる＝はっきり見せる」と覚えよう。⚠️ lumber（材木）、lucky（幸運な）は「光」と無関係。

-liber-自由的；使自由自由な；自由にするLatin liber, liberare

来自拉丁语 liber（自由的）和 liberare（使自由）。自由人的 → 慷慨、宽松 → liberal / liberally；自由 → liberty（take the liberty of ~ing 冒昧……）；使自由 → liberate（解放）；放宽 → liberalize。后期拉丁语 deliberare“使自由”经古法语 delivrer 成为 deliver（放出 → 交出 → 递送、发表）/ delivery / deliverable。⚠️ 两个陷阱：deliberate（深思熟虑）来自 libra“天平”；library（图书馆）来自另一个 liber“书、树皮”，都与“自由”无关。ラテン語 liber（自由な）と liberare（自由にする）から。自由人らしい → 気前のよい・寛大な → liberal／liberally、自由 → liberty（take the liberty of ~ing 勝手ながら〜する）、自由にする → liberate（解放する）、規制を緩める → liberalize。後期ラテン語 deliberare「自由にする」が古フランス語 delivrer を経て deliver（放す → 引き渡す → 配達する・講演する）／delivery／deliverable に。⚠️ 落とし穴が 2 つ：deliberate（熟考した）は libra「天秤」由来、library（図書館）は別の liber「本・樹皮」由来で、どちらも「自由」とは無関係。

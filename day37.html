-act- / -ag-做；行动行う；動くLatin agere, actus

来自拉丁语 agere（做、推动）及其过去分词 actus。启动 → activate / deactivate；反过来做 → react / reaction；相互作用 → interact / interaction；先行动 → proactive；不活动 → inactive。⚠️ act 的核心是“做”，别和 action 的 -tion 后缀混在一起拆。ラテン語 agere（行う・動かす）とその過去分詞 actus から。作動させる → activate／deactivate；逆に行う → react／reaction；互いに作用 → interact／interaction；先に動く → proactive；活動しない → inactive。⚠️ act の核心は「行う」。

-migr-迁移；移动移る；移動するLatin migrare

来自拉丁语 migrare（迁移）。迁往 → migrate / migration；迁移的人 → migrant；迁入 → immigrate / immigration / immigrant（im- = in-）；迁出 → emigrate / emigrant（e- = ex-）。⚠️ immigrate to 指移入，emigrate from 指移出。ラテン語 migrare（移る）から。移る → migrate／migration；移動する人 → migrant；入ってくる → immigrate／immigration／immigrant（im- = in-）；出ていく → emigrate／emigrant（e- = ex-）。⚠️ immigrate to は入る側、emigrate from は出る側。

-urb-城市都市Latin urbs

来自拉丁语 urbs（城市）。城市的 → urban；靠近城市（sub- 靠近）→ suburb / suburban / suburbia；城市之间（inter-）→ interurban；使城市化 → urbanize / urbanization；有城里人风度 → urbane。⚠️ urbane（文雅）与 urban（城市的）形近义异。ラテン語 urbs（都市）から。都市の → urban；都市の近く（sub- 近く）→ suburb／suburban／suburbia；都市間（inter-）→ interurban；都市化する → urbanize／urbanization；都会人らしい → urbane。⚠️ urbane（洗練された）と urban（都市の）は紛らわしい。

-text-编织；文本織る；文章Latin texere, textus

来自拉丁语 texere（编织），过去分词 textus（织成物 → 文章）。文章 → text / textual；交织在一起的前后文 → context / contextual；织物的质感 → texture / textured；事先织在前面的说辞 → pretext；文字之下的意思 → subtext。⚠️ textile（纺织品）同源，已学。ラテン語 texere（織る）、過去分詞 textus（織られたもの → 文章）から。文章 → text／textual；織り合わさった前後の文 → context／contextual；織物の質感 → texture／textured；前に織りつけた言い分 → pretext；文章の下の意味 → subtext。⚠️ textile（織物）も同源（学習済み）。

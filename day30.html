-junct- / -join-连接；结合つなぐ；結びつけるLatin jungere, junctus

拉丁语 jungere“连接、套上轭”，过去分词 junctus。经法语变成 join / joint：joint（连接处；联合的）→ jointly，ad- → adjoin / adjoining（连在旁边 → 邻接的），re- → rejoin（重新连上 → 重新加入），dis- → disjointed（拆开的 → 不连贯的）。保留拉丁拼写 junct 的有：junction（交叉口，已学）、con- → conjunction（连在一起 → 结合；连词）、juncture（连接点 → 关头）、ad- → adjunct（附加上的 → 辅助的；兼职的）。⚠️ junior 来自 juvenis“年轻的”，June 来自女神 Juno，都与 junct 无关。ラテン語 jungere「つなぐ・くびきをかける」、過去分詞 junctus。フランス語を経て join／joint に：joint（継ぎ目；共同の）→ jointly、ad- → adjoin／adjoining（隣につながる → 隣接した）、re- → rejoin（再びつながる → 復帰する）、dis- → disjointed（ばらばらの → まとまりのない）。ラテン語のつづり junct を残すのは junction（交差点、既習）、con- → conjunction（結合；接続詞）、juncture（接合点 → 局面）、ad- → adjunct（付け加えられた → 補助の；非常勤の）。⚠️ junior は juvenis「若い」、June は女神 Juno 由来で無関係。

拉丁语 pati“忍受、承受”，过去分词 passus。现在分词 patiens → patient（能忍受的 → 有耐心的；承受病痛的人 → 病人）/ patience / impatient；com- + pati“一起承受”→ compatible（兼容的）/ compatibility / incompatible；passio“受苦 → 强烈情感”→ passion / passionate；passivus“承受动作的”→ passive（被动的）。⚠️ pass（通过）、passenger、passport 来自 passus“脚步”（pandere“伸开”），与“忍受”无关；patent（专利）来自 patere“敞开”，patron 来自 pater“父亲”，也都不是同族。ラテン語 pati「耐える・受ける」、過去分詞 passus。現在分詞 patiens → patient（耐えられる → 我慢強い；病に耐える人 → 患者）／patience／impatient。com-＋pati「共に耐える」→ compatible（互換性のある）／compatibility／incompatible。passio「苦しみ → 激しい感情」→ passion／passionate。passivus「動作を受ける」→ passive（受け身の）。⚠️ pass（通る）・passenger・passport は passus「歩み」（pandere「広げる」）由来で「耐える」とは無関係。patent（特許）は patere「開いている」、patron は pater「父」由来で、これらも別語源。

-lat-带；搬运運ぶ；持っていくLatin latus (past participle of ferre)

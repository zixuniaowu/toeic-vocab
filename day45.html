-pel- / -puls-推；驱押す；駆るLatin pellere, pulsus

来自拉丁语 pellere（推）。推回去 → repel；从内部推动 → impel；向前推 → propulsion。⚠️ appeal（上诉；吸引）来自 appellare“呼唤”，不属于此词根。ラテン語 pellere（押す）から。押し返す → repel；内から駆り立てる → impel；前へ押す → propulsion。⚠️ appeal は appellare「呼びかける」由来で別語根。

-rupt-破；断破る；断つLatin rumpere, ruptus

来自拉丁语 rumpere（打破）。冲破而出 → erupt；彻底败坏 → corruption；断开般地 → abruptly。⚠️ rapture（狂喜）来自 rapere“夺取”，不属于此词根。ラテン語 rumpere（破る）から。破って噴き出す → erupt；完全に壊す → corruption；ぷつりと断つ → abruptly。⚠️ rapture（歓喜）は rapere「奪う」由来で別語根。

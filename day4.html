-pos- / -pon- / -pound-放置；摆放置く；据えるLatin ponere / positus

来自拉丁语 ponere（放置；过去分词 positus）。变体 pos / pon / pound（com+ponere → compound）。前缀：pro-（往前放 → 提议）、dis-（分开放 → 处理／丢弃）、ex-（放出来 → 暴露）、com-（放一起 → 组成）、ob-（对着放 → 反对）、im-（放上去 → 强加）。名词常为 -position / -posal。⚠️ purpose、positive 看起来像但不同源，勿硬拆。ラテン語 ponere（置く、過去分詞 positus）から。異形 pos / pon / pound。接頭辞：pro-（前に置く → 提案する）、dis-（分けて置く → 処分する）、ex-（外に出す → さらす）、com-（共に置く → 構成する）、ob-（向かい合わせて置く → 反対する）、im-（上に置く → 課す）。名詞は -position / -posal。⚠️ purpose や positive は別語源。

-ven- / -vent-来；到来来る；到来するLatin venire / ventus

来自拉丁语 venire（来；过去分词 ventus）。前缀：in-（进来／想出来 → 发明）、pre-（预先来挡住 → 防止）、inter-（来到中间 → 介入）、con-（一起来 → 大会／惯例）、ad-（向…来 → 冒险／到来）。名词常为 -vention / -venue。⚠️ invent 的“发明”义来自“想出来”；revenue、venue 同源但本站另课已提醒播客重叠时尽量避开。ラテン語 venire（来る、過去分詞 ventus）から。接頭辞：in-（中へ来る／思い浮かぶ → 発明する）、pre-（先に来て阻む → 防ぐ）、inter-（間に入る → 介入する）、con-（共に来る → 大会／慣例）、ad-（〜へ来る → 冒険／到来）。名詞は -vention が多い。

-grad- / -gress-走；迈步歩む；進むLatin gradi / gressus

来自拉丁语 gradi（走；过去分词 gressus）。grad 多表“级别／程度”，gress 多表“前进／行走”。前缀：pro-（向前走 → 进步）、de-（往下走 → 降级）、di-（走开 → 离题）、ad-（向…走 → 侵略的）、re-（往回走 → 倒退）。⚠️ congress 本义“走到一起”，业务场景较少；grade 单独也可看作同源。ラテン語 gradi（歩む、過去分詞 gressus）から。grad は「段階」、gress は「前進」のニュアンス。接頭辞：pro-（前へ進む → 進歩）、de-（下へ → 格下げ）、di-（脇へそれる → 脱線する）、ad-（向かって進む → 攻撃的な）、re-（戻る → 後退）。

-cap- / -cept- / -ceive- / -cip-拿；取；抓住取る；つかむLatin capere / captus

来自拉丁语 capere（拿、取；过去分词 captus）。变体 cept / ceive / cip。前缀：ac-（向自己拿 → 接受）、ex-（拿出去 → 除了）、re-（拿回来 → 收到／接受者）、per-（彻底拿住 → 察觉）、con-（一起拿／想出 → 构想）、cap-（抓住 → 捕获）。capable 来自“有能力拿住”。⚠️ except 与 accept 只差一个字母，Part 5 常考。ラテン語 capere（取る、過去分詞 captus）から。異形 cept / ceive / cip。接頭辞：ac-（自分の方へ取る → 受け入れる）、ex-（取り出す → 〜を除いて）、re-（取り戻す → 受け取る／受取人）、per-（しっかりつかむ → 知覚する）、con-（思い浮かべる → 構想する）。capable は「つかみ取れる力がある」。⚠️ except と accept は1文字違いで Part 5 頻出。

-via- / -vey- / -voy-道路；经过道；経由Latin via

来自拉丁语 via（道路）。con-“一起”上路 → convey（护送 → 运送、传达）→ conveyor（传送带）；ob-“挡在面前”的路 → obvious（明显的）；pre-“走在前面” → previous（以前的）；de-“离开”道路 → deviate（偏离）；tri-“三岔路口”的闲谈 → trivial（琐碎的）；viaticum“旅费” → 古法语 voiage → voyage（航行）。英语里 via 本身也表示“经由”（via email）。⚠️ convey 的 vey、voyage 的 voy 都是 via 的变体；vivid、vital 属于 viv/vit“生命”，不是 via。ラテン語 via（道）から。con-「一緒に」道を行く → convey（護送 → 運ぶ・伝える）→ conveyor（コンベヤー）。ob-「目の前の」道 → obvious（明らかな）。pre-「前を行く」→ previous（以前の）。de-「道から外れる」→ deviate（逸脱する）。tri-「三叉路」での世間話 → trivial（ささいな）。viaticum「旅費」→ 古フランス語 voiage → voyage（航海）。英語の via 自体も「〜経由で」（via email）。⚠️ convey の vey、voyage の voy は via の変形。vivid・vital は「命」の viv／vit で別語源。

-memor- / -member-记忆；记得記憶；覚えているLatin memor, memoria

来自拉丁语 memor（记得的）、memoria（记忆）。memory（记忆）→ memorable（难忘的）、memorial（纪念碑）、memorize（背诵）；memorandum“应记住的事” → memo（备忘录）；com-“共同”记住 → commemorative（纪念的）；re-“再”想起 → 古法语 remembrer → remember（记得）→ remembrance（纪念）。⚠️ remember 里的 member 与“会员”member（拉丁语 membrum“肢体”）不同源。ラテン語 memor（覚えている）、memoria（記憶）から。memory（記憶）→ memorable（忘れられない）、memorial（記念碑）、memorize（暗記する）。memorandum「覚えておくべきこと」→ memo（社内メモ）。com-「共に」思い起こす → commemorative（記念の）。re-「再び」思い出す → 古フランス語 remembrer → remember → remembrance（追悼）。⚠️ remember の member と「会員」member（ラテン語 membrum「手足」）は別語源。

-sci-知道知るLatin scire, scientia

来自拉丁语 scire（知道），scientia“知识” → science（科学）→ scientific（科学的）、scientist（科学家）；con-“共同/完全”知道 → conscius → conscious（意识到的）→ unconscious、consciousness（意识）；conscientia“内心知道是非” → conscience（良心）→ conscientious（尽责的）。⚠️ conscience（良心）≠ conscious（意识到的）≠ conscientious（认真的）是 Part 5 易混组；scissors、scenic 与 sci 无关。ラテン語 scire（知る）から。scientia「知識」→ science → scientific、scientist。con-「共に・完全に」知る → conscius → conscious（意識している）→ unconscious、consciousness（意識）。conscientia「善悪を内心で知ること」→ conscience（良心）→ conscientious（誠実な）。⚠️ conscience／conscious／conscientious は Part 5 の紛らわしい組。scissors・scenic は sci と無関係。

-vit- / -viv-生命；活命；生きるLatin vita / vivere

来自拉丁语 vita（生命）和 vivere（活）。vitalis“生命的” → vital（至关重要的）→ vitality（活力）；vita + amine → vitamin（维生素）；re-“再”活 → revive（复苏）→ revival；sur-（super，超过）+ vivere → survive（幸存、挺过）→ survival；vividus“充满生命的” → vivid（鲜艳的）。⚠️ visit、vision 属于 vis“看”，invite 也与 vit 无关。ラテン語 vita（命）と vivere（生きる）から。vitalis「生命の」→ vital（極めて重要な）→ vitality（活力）。vita + amine → vitamin。re-「再び」生きる → revive（復活させる）→ revival。sur-（super「越えて」）+ vivere → survive（生き残る）→ survival。vividus「生気に満ちた」→ vivid（鮮やかな）。⚠️ visit・vision は「見る」の vis、invite も vit とは無関係。

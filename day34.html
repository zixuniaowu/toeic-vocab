-aud- / -audi-听聞くLatin audire

来自拉丁语 audire（听）。能听见的 → audible，加 in-“不”→ inaudible；听的人 → audience（观众、受众）；听账的人 → auditor（审计员，古代账目是念出来让人听着核对的）；听讲的地方 → auditorium（礼堂）；与听觉有关 → auditory；audio（音频）原意就是“我听”；audio + visual → audiovisual（视听的）。⚠️ audacious（大胆的）来自 audere“敢”，与“听”无关。ラテン語 audire（聞く）から。聞こえる → audible、in-「〜でない」→ inaudible。聞く人たち → audience（観客・受け手）。帳簿を聞いて確かめる人 → auditor（監査人。昔は帳簿を読み上げて確認した）。聞く場所 → auditorium（講堂）。聴覚の → auditory。audio はもともと「私は聞く」。audio＋visual → audiovisual（視聴覚の）。⚠️ audacious（大胆な）は audere「あえてする」由来で「聞く」とは無関係。

-capit- / -chief- / -chiev-头；首领頭；長Latin caput, capitis

来自拉丁语 caput（头）。头部的 → 首要的 → capital（资本、首都、大写字母），capitalize（利用；大写）、capitalization（市值）；首领 → captain（机长、队长）；经法语变成 chief（首席的），厨房之首 → chef；“小头”→ 段落标题 → chapter（章、分会）；“做到头”→ achieve（实现）→ achievement。⚠️ cap- 表“拿”（capture、capable）来自 capere，与“头”不同源。ラテン語 caput（頭）から。頭の → 最重要の → capital（資本・首都・大文字）、capitalize（活かす；大文字にする）、capitalization（時価総額）。長 → captain（機長・主将）。フランス語経由で chief（最高位の）、厨房の長 → chef。「小さな頭」→ 見出し → chapter（章・支部）。「頭（端）まで行く」→ achieve（達成する）→ achievement。⚠️「取る」の cap-（capture、capable）は capere 由来で「頭」とは別。

-cand- / -chand-发光；白輝く；白いLatin candere, candidus

来自拉丁语 candere（发白光）和 candidus（白的）。发光的东西 → candle（蜡烛），经法语 → chandelier（吊灯，原为烛台）；开始发白光 → incandescent（白炽的）；白 → 纯净 → 坦诚 → candid / candidly / candor；古罗马竞选者穿白袍 → candidate（候选人）→ candidacy（参选）。ラテン語 candere（白く輝く）と candidus（白い）から。光るもの → candle（ろうそく）、フランス語経由で chandelier（シャンデリア、もとは燭台）。白く輝き始める → incandescent（白熱の）。白い → 汚れのない → 率直な → candid／candidly／candor。古代ローマの立候補者は白い衣を着た → candidate（候補者）→ candidacy（立候補）。

-greg-群；聚集群れ；集めるLatin grex, gregis

来自拉丁语 grex（羊群）。加入群 → aggregate（总计的）/ aggregation（汇总）；聚成一群 → congregate（聚集）/ congregation（会众）；从群里分出 → segregate（分开）/ segregation（分离）；喜欢群体 → gregarious（爱交际的）；超出群体 → egregious（原为“出众的”，现指“极其糟糕的”）。ラテン語 grex（羊の群れ）から。群れに加える → aggregate（総計の）／aggregation（集約）。一つの群れにまとめる → congregate（集まる）／congregation（会衆）。群れから離す → segregate（分ける）／segregation（分別）。群れを好む → gregarious（社交的な）。群れから抜きん出る → egregious（もとは「抜群の」、今は「ひどい」）。

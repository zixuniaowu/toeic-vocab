-magn- / -maj- / -max-大大きいLatin magnus, major, maximus

来自拉丁语 magnus（大），比较级 major（更大），最高级 maximus（最大）——三个形式正好是“大 → 更大 → 最大”。magnus → magnify（放大）/ magnitude（规模）/ magnificent（壮丽的，magnus + facere“做大事”）/ magnate（大亨）；major → major（主要的）/ majority（大多数）；maximus → maximum（最大量）/ maximize（最大化）。反义一组来自 minor / minimus：minority、minimum、minimize。⚠️ magnet（磁铁）来自希腊地名 Magnesia，magazine（杂志 / 仓库）来自阿拉伯语 makhāzin，都与“大”无关。ラテン語 magnus（大きい）、比較級 major（より大きい）、最上級 maximus（最大の）から。「大 → より大 → 最大」の三段活用。magnus → magnify（拡大する）／magnitude（規模）／magnificent（壮大な。magnus＋facere「大きなことをする」）／magnate（大物）。major → major（主要な）／majority（大多数）。maximus → maximum（最大限）／maximize（最大化する）。反対は minor / minimus：minority、minimum、minimize。⚠️ magnet（磁石）はギリシャの地名 Magnesia、magazine（雑誌・倉庫）はアラビア語 makhāzin 由来で「大きい」とは無関係。

-dom- / -domin-家；主人家；主人Latin domus, dominus

来自拉丁语 domus（家），一家之主叫 dominus（主人）。“家”这一支：domestic（国内的、家庭的——把“国家”看成一个大家）/ domestically；“主人 → 统治”这一支：dominate（主导）/ dominant（占主导的）/ predominant（占多数的，pre-“在前”）/ predominantly / domain（主人的领地 → 领域、域名）/ condominium（con-“共同”+ 所有权 → 产权公寓，简称 condo）。⚠️ freedom、kingdom 里的 -dom 是古英语后缀 dōm“状态、领域”，与拉丁语 domus 无关；random 也无关。ラテン語 domus（家）と、家の主人 dominus から。「家」の系統：domestic（国内の・家庭の。国をひとつの家と見る）／domestically。「主人 → 支配」の系統：dominate（支配する）／dominant（優勢な）／predominant（主な。pre-「前に」）／predominantly／domain（主人の領地 → 領域・ドメイン）／condominium（con-「共同」＋所有権 → 分譲マンション、略して condo）。⚠️ freedom、kingdom の -dom は古英語の接尾辞 dōm「状態・領域」でラテン語 domus とは無関係。random も無関係。

-sat- / -satis- / -satur-足够；饱满十分；満ちたLatin satis, satur

来自拉丁语 satis（足够）和同源的 satur（吃饱的）。satis + facere“做” → satisfy（使满意 = 做到足够）→ satisfactory（合格的）/ satisfactorily / unsatisfactory / dissatisfaction（不满）；satur → saturate（使饱和）/ saturated（饱和的）/ saturation（饱和）。已学过的 asset（资产）也来自 ad satis“达到足够”——原指足以偿债的财产。⚠️ satellite（卫星）和 Saturday（土星 Saturn 之日）都与 satis 无关。satisfactory 重点是“达标”，不等于“非常满意”。ラテン語 satis（十分）と同源の satur（満腹の）から。satis＋facere「する」→ satisfy（満足させる＝十分にする）→ satisfactory（十分な・合格の）／satisfactorily／unsatisfactory／dissatisfaction（不満）。satur → saturate（飽和させる）／saturated（飽和した）／saturation（飽和）。既習の asset（資産）も ad satis「十分に」から——借金を返すのに十分な財産、が元の意味。⚠️ satellite（衛星）や Saturday（土星 Saturn の日）は satis と無関係。satisfactory は「基準を満たす」が中心で「大満足」ではない。

-cult-耕种；培育耕す；育てるLatin colere, cultus

来自拉丁语 colere（耕种、照料），过去分词 cultus。耕地 → 培养人 → 文化：culture（文化、企业风气）/ cultural / multicultural（多元文化的）/ cross-cultural（跨文化的）；“耕种”本义：cultivation（种植、培养）/ cultivated（人工种植的）/ agriculture（ager“田地”+ 耕种 → 农业）/ horticulture（hortus“园子”+ 耕种 → 园艺）。⚠️ consult（咨询）来自 consulere，difficult 来自 facilis，虽然拼写里有 cult，都与“耕种”无关。ラテン語 colere（耕す・世話する）、過去分詞 cultus から。畑を耕す → 人を育てる → 文化：culture（文化・企業風土）／cultural／multicultural（多文化の）／cross-cultural（異文化間の）。「耕す」の本義：cultivation（栽培・育成）／cultivated（栽培された）／agriculture（ager「畑」＋耕作 → 農業）／horticulture（hortus「庭」＋耕作 → 園芸）。⚠️ consult（相談する）は consulere、difficult は facilis 由来で、つづりに cult があっても「耕す」とは無関係。

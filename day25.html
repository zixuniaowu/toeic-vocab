-sta- / -stat-站立；稳定；状态立つ；安定；状態Latin stare, status

来自拉丁语 stare（站立），过去分词 status。stabilis“站得稳的” → stable（稳定的）→ stability，stabilire“使稳固” → 古法语 establir → establish → establishment（机构、营业场所）；status“站立的样子、状态” → status、state（状态；国家；陈述）→ 古法语 estat → estate（地产）；statio“停留处” → station → stationary（静止的）；statuere“使站立” → statue（雕像）。⚠️ stationary（静止的）≠ stationery（文具）；statistics 也来自 status，但 stack、stamp 与 sta 无关。ラテン語 stare（立つ）、過去分詞 status から。stabilis「しっかり立つ」→ stable（安定した）→ stability。stabilire「固める」→ 古フランス語 establir → establish → establishment（施設・店舗）。status「立っている様子・状態」→ status、state（状態・国家・述べる）→ 古フランス語 estat → estate（不動産）。statio「止まる所」→ station → stationary（静止した）。statuere「立てる」→ statue（像）。⚠️ stationary（静止した）≠ stationery（文房具）。statistics も status 由来だが、stack・stamp は無関係。

来自拉丁语 nasci（出生），过去分词 natus。nativus“天生的” → native（本地的、母语的）；natura“天生的样子” → nature（性质、自然）→ natural、naturally；natio“同一出生的人群” → nation → national、nationality，inter-“之间” + national → international（国际的）；in-“在内” + natus → innate（天生的）。⚠️ innate 的 in- 是“在内”不是“不”；nasty、navy 与 nat 无关。ラテン語 nasci（生まれる）、過去分詞 natus から。nativus「生まれつきの」→ native（その土地の・母語の）。natura「生まれつきの姿」→ nature（性質・自然）→ natural、naturally。natio「生まれを同じくする人々」→ nation → national、nationality。inter-「間」+ national → international（国際的な）。in-「内に」+ natus → innate（生まれつきの）。⚠️ innate の in- は「内に」で否定ではない。nasty・navy は nat と無関係。

-pot- / -poss-能够；有力できる；力があるLatin posse, potens

来自拉丁语 posse（能够，potis“有能力的” + esse“是”）和 potens（有力的）。potentia“能力” → potential（潜在的；潜力）→ potentially；potens → potent（强有力的）；possibilis → possible → possibility，in- + possible → impossible；通俗拉丁语 *potere → 古法语 poeir → power（电力、能力）→ powerful。⚠️ potted（盆栽的）的 pot 是本族词“罐子”，和这里的 pot“能够”无关；possession（拥有，本站已学）也来自 potis + sedere“坐”，今天不重复。ラテン語 posse（できる。potis「力のある」+ esse「ある」）と potens（力がある）から。potentia「能力」→ potential（潜在的な・可能性）→ potentially。potens → potent（強力な）。possibilis → possible → possibility、in- + possible → impossible。俗ラテン語 *potere → 古フランス語 poeir → power（電力・力）→ powerful。⚠️ potted（鉢植えの）の pot は本来語「つぼ」で、この pot「できる」とは無関係。

-scend- / -scal-攀登；梯子よじ登る；はしごLatin scandere / scala

来自拉丁语 scandere（攀登），名词 scala（梯子）也出自同一词根。ad-“向” + scandere → ascend（上升）→ ascent；de-“向下” + scandere → descend（下降）→ descent、descendant（后代）；trans-“越过” + scandere → transcend（超越）；con- + descendere → condescend → condescending（居高临下的）；scala“梯子” → escalade“爬梯攻城” → escalator（自动扶梯）。⚠️ ascent（上升）与 assent（同意）同音；descent 与 decent（体面的）形近音不同；scent（气味）来自 sentire“感觉”，与 scend 无关。ラテン語 scandere（よじ登る）から。名詞 scala（はしご）も同じ語根。ad-「〜へ」+ scandere → ascend（上がる）→ ascent。de-「下へ」+ scandere → descend（下りる）→ descent、descendant（子孫）。trans-「越えて」+ scandere → transcend（超える）。con- + descendere → condescend → condescending（見下すような）。scala「はしご」→ escalade「はしごで城壁を登ること」→ escalator。⚠️ ascent（上昇）と assent（同意）は同音。descent と decent（まともな）は綴りが似ているが発音が違う。scent（香り）は sentire「感じる」由来で scend とは無関係。

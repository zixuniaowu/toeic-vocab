-oper-工作；作品仕事；作品Latin opus, operis / operari

来自拉丁语 opus（复数 opera，工作、作品）和 operari（工作、起作用）。operate（操作、运营）→ operational（运营上的；可运转的）、operator（操作员；接线员；经营者）、operative（起作用的；生效的）；in-“不” + operable → inoperable（无法运转的）；co-“一起” + operari → cooperate（合作）→ cooperation、cooperative；意大利语 opera“作品” → opera（歌剧）。⚠️ opportunity 来自 portus“港口”，optimal 来自 optimus“最好的”，都和 oper 无关。ラテン語 opus（複数 opera、仕事・作品）と operari（働く・作用する）から。operate（操作する・運営する）→ operational（運用上の；稼働可能な）、operator（オペレーター；交換手；事業者）、operative（効力のある；稼働中の）。in-「否定」+ operable → inoperable（作動しない）。co-「共に」+ operari → cooperate（協力する）→ cooperation、cooperative。イタリア語 opera「作品」→ opera（オペラ）。⚠️ opportunity は portus「港」、optimal は optimus「最良の」から来ており oper とは無関係。

-alter- / -ali-另一个；别的もう一方の；他のLatin alter / alius

来自拉丁语 alter（两者中的另一个）和 alius（别的）。alter → 中世纪拉丁语 alterare“使变成另一个样子” → alter（修改）、unaltered（未改动的）；alternare“轮流” → alternate（交替）、alternative（另一个选择）、alternatively；alius → alienus“属于别人的” → alien（外国的；陌生的）→ alienate（疏远）；拉丁语副词 alias“在别的时候；否则” → alias（化名；别名）。⚠️ altitude 来自 altus“高”，altar 是“祭坛”，都和 alter 无关。ラテン語 alter（二つのうちのもう一方）と alius（他の）から。alter → 中世ラテン語 alterare「別のものにする」→ alter（変更する）、unaltered（変更されていない）。alternare「交互に行う」→ alternate（交互に行う）、alternative（代わりの選択肢）、alternatively。alius → alienus「他人に属する」→ alien（外国の；なじみのない）→ alienate（遠ざける）。ラテン語の副詞 alias「別の時に；別名で」→ alias（別名）。⚠️ altitude は altus「高い」、altar は「祭壇」で、alter とは無関係。

-pel- / -puls-推；驱动押す；駆り立てるLatin pellere / pulsus

来自拉丁语 pellere（推、驱赶；过去分词 pulsus）。com-（一起推 → 强迫）、ex-（推出去 → 开除）、pro-（向前推 → 推进）、dis-（推散 → 消除）、re-（推回 → 击退、防…）、im-（向内推 → 冲动）。⚠️ appeal（呼吁）来自 appellare“称呼”，和 pellere 不同。ラテン語 pellere（押す・追い払う、過去分詞 pulsus）から。com-（共に押す → 強いる）、ex-（押し出す → 追放）、pro-（前へ押す → 推進）、dis-（散らす → 払拭する）、re-（押し返す → 撃退する）、im-（中へ押す → 衝動）。⚠️ appeal は appellare「呼びかける」由来で別。

-fin-结束；界限終わり；境界Latin finis / finire

来自拉丁语 finis（边界、终点）和 finire（结束）。final“最终的”、confine“划定边界 → 限制”、define“划清界限 → 定义”、refine“再使精细 → 提炼、改进”、infinite“无边界的”。finance 原指“了结债务”。⚠️ fine（罚款）也来自 finis（了结的款项）。ラテン語 finis（境界・終わり）と finire（終える）から。final「最終の」、confine「境界を定める → 限る」、define「境界をはっきりさせる → 定義する」、refine「さらに細かくする → 洗練する」、infinite「境界のない」。finance は元「借金を片付ける」。⚠️ fine（罰金）も finis 由来。

-sequ- / -secu- / -su-跟随従う；続くLatin sequi / secutus

来自拉丁语 sequi（跟随；过去分词 secutus）。con-（一起跟着来 → 结果）、sub-（随后 → 随后的）、ex- + secu（跟到底 → 执行）、per-（一直追 → 追求）。⚠️ 经法语变为 su-：pursue、suit、suite 也属此家族；second（第二）也来自 sequi“跟在后面的”。ラテン語 sequi（従う、過去分詞 secutus）から。con-（共についてくる → 結果）、sub-（後に続く → その後の）、ex-＋secu（最後まで追う → 実行する）、per-（追い続ける → 追求する）。⚠️ フランス語経由で su- に：pursue・suite も仲間。second（2 番目）も sequi「後に続く」から。

-volv- / -volu- / -volt-卷；转巻く；回るLatin volvere / volutus

来自拉丁语 volvere（卷、转；过去分词 volutus）。re-（转回来 → 旋转、周转）、in-（卷进去 → 涉及）、e-（展开 → 演变）、de-（卷下去 → 移交）。volume 原指“卷轴 → 书的一卷 → 量、音量”。⚠️ volunteer 来自 voluntas“意愿”，不同源。ラテン語 volvere（巻く・回す、過去分詞 volutus）から。re-（回転する）、in-（巻き込む → 関わらせる）、e-（巻物を広げる → 発展する）、de-（転がり落ちる → 委ねる）。volume は「巻物 → 1 巻 → 量・音量」。⚠️ volunteer は voluntas「意志」由来で別。

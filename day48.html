-port-携带；搬运運ぶLatin portare

来自拉丁语 portare（搬运）。把消息带回 → reporter；运进来 → importer；运出去 → exportable。⚠️ portal（门户）来自 porta“门”，与 port“搬运”不同源。ラテン語 portare（運ぶ）から。情報を持ち帰る → reporter；運び込む → importer；運び出す → exportable。⚠️ portal（入口）は porta「門」由来で別系統。

-duc- / -duct-引导；带领導くLatin ducere, ductus

来自拉丁语 ducere（引导）。引进来 → introduction；引回去 → reduction；引出潜力 → educator。⚠️ duck（鸭子）与此无关。ラテン語 ducere（導く）から。導き入れる → introduction；引き戻す → reduction；能力を引き出す → educator。⚠️ duck（アヒル）は無関係。

-ject-投掷；抛投げるLatin jacere, jectus

来自拉丁语 jacere（投）。向外扔 → ejection；在中间扔进 → interject；向下扔 → dejection。⚠️ jet（喷射）与 jettison 同源，但 jacket 无关。ラテン語 jacere（投げる）から。外へ投げる → ejection；間に投げ込む → interject；下へ投げる → dejection。⚠️ jacket（上着）は無関係。

-firm-坚固；确定固い；確かなLatin firmus, firmare

来自拉丁语 firmus（坚固的、稳固的）。使之确定 → confirm（确认）/ confirmed / unconfirmed；向外表明“是这样” → affirm（断言）/ reaffirm（重申）/ affirmative（肯定的）；稳固地 → firmly。名词 firm“公司”源自签字确认的商号，也是同一个词。⚠️ farm（农场）与 firm 不同源。ラテン語 firmus（固い・しっかりした）から。確かにする → confirm（確認する）／confirmed／unconfirmed。「そうだ」と表明する → affirm（断言する）／reaffirm（再確認する）／affirmative（肯定の）。しっかりと → firmly。名詞 firm「会社」も署名で確定した商号に由来する同じ語。⚠️ farm（農場）は別語源。

-fess- / -fes-承认；宣称認める；公言するLatin fateri, fessus

来自拉丁语 fateri（承认、说出）及其过去分词 fessus。公开宣称 → profess（声称）/ profession（公开宣誓从事的职业）/ professional / professionally / professionalism；公开讲授的人 → professor（教授）；完全承认 → confess（坦白）/ confession。⚠️ festival、feast 来自 festus“节日”，与 fess 不同源。ラテン語 fateri（認める・言う）とその過去分詞 fessus から。公言する → profess（公言する）／profession（公に誓って就く職業）／professional／professionally／professionalism。公に講じる人 → professor（教授）。すっかり認める → confess（白状する）／confession。⚠️ festival や feast は festus「祭り」由来で別語源。

-mut-改变；交换変える；交換するLatin mutare, mutuus

来自拉丁语 mutare（改变、交换）。完全交换 → commute（通勤：以月票替换车费）/ commutation（通勤补贴）；彼此交换 → mutual（相互的）/ mutually；能变 → mutable，不能变 → immutable；变化本身 → mutation（突变）；彻底变形 → transmute。⚠️ mute（沉默的）来自 mutus，与“改变”不同源。ラテン語 mutare（変える・交換する）から。すっかり交換する → commute（通勤：定期券で運賃を置き換える）／commutation（通勤手当）。互いに交換 → mutual（相互の）／mutually。変えられる → mutable、変えられない → immutable。変化そのもの → mutation（突然変異）。姿を変える → transmute。⚠️ mute（無言の）は mutus 由来で別。

-vol-意愿；希望意志；望むLatin velle, volo

来自拉丁语 velle / volo（愿意、想要）。出于意愿的 → voluntary（自愿的）/ voluntarily / involuntary（非自愿的）；自愿的人 → volunteer / volunteerism；意志本身 → volition；愿人好 → benevolence（善意），愿人坏 → malevolent（恶意的）。⚠️ volume、revolve、involve 属于 volv-“卷、转”（第 9 天）；voltage 来自人名 Volta，都与“意愿”无关。ラテン語 velle／volo（望む）から。意志による → voluntary（自発的な）／voluntarily／involuntary（不本意の）。自ら申し出る人 → volunteer／volunteerism。意志そのもの → volition。人の幸せを願う → benevolence（善意）、不幸を願う → malevolent（悪意ある）。⚠️ volume・revolve・involve は volv-「巻く・回る」（Day 9）、voltage は人名 Volta 由来で、どれも「意志」とは無関係。

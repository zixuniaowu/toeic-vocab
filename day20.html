-fid- / -fi-信任；信义信頼；信義Latin fides; fidere

来自拉丁语 fides（信任、信义）和动词 fidere（信任）。con-“完全” → confidere“完全信任” → confident、confidence、confide；本站已学的 confidential（机密的 = 托付给信任的人）也在这个家族。dis-（dif-）“不” → diffident“不自信的”；fidelis“忠实的” → fidelity。ad- + fidare → affidavit“他已宣誓保证 → 宣誓书”。古法语 desfier“放弃信义” → defy“违抗”。法语里 fides 变成 feid → faith、faithfully。⚠️ defy 的 -fy 不是 justify 里的 -fy（facere“做”）。⚠️ finance、final 来自 finis“终点”（Day 9 的 fin），不是这个词根。ラテン語 fides（信頼・信義）と動詞 fidere（信頼する）から。con-「完全に」→ confidere「すっかり信頼する」→ confident、confidence、confide。既習の confidential（信頼できる人に託す → 機密の）も同じ仲間。dis-（dif-）「〜でない」→ diffident「自信のない」。fidelis「忠実な」→ fidelity。ad- + fidare → affidavit「彼は誓約した → 宣誓供述書」。古フランス語 desfier「信義を捨てる」→ defy「逆らう」。フランス語で fides が feid になり → faith、faithfully。⚠️ defy の -fy は justify の -fy（facere「する」）ではない。⚠️ finance・final は finis「終わり」（Day 9 の fin）から来ており、この語根ではない。

来自拉丁语 sedere（坐），过去分词 sessus；sidere“坐下、沉下”是它的同族动词。re-“留下” → residere“留下来坐着” → reside、residence、residue“剩下的东西”；prae-“在前” → praesidere“坐在前面” → preside、president；sub-“在下” → subside“沉下 → 平息”，本站已学的 subsidy、subsidiary 也来自 subsidium“坐在后面的预备队”；ad- → assidere“坐在旁边协助评定” → assess、assessment；potis“有能力的” + sedere → possidere“坐在上面 → 占有” → possess、possession；sedentarius → sedentary“久坐的”。session（会议、一段时间）也是“坐着开会”。⚠️ site、situation 来自 situs“位置”，不是 sedere。ラテン語 sedere（座る）、過去分詞 sessus から。sidere「座り込む・沈む」は同族の動詞。re-「残って」→ residere「座ったままでいる」→ reside、residence、residue「残ったもの」。prae-「前に」→ praesidere「前に座る」→ preside、president。sub-「下に」→ subside「沈む → 収まる」。既習の subsidy・subsidiary も subsidium「後ろに控える予備隊」から。ad- → assidere「そばに座って査定を補佐する」→ assess、assessment。potis「力がある」+ sedere → possidere「上に座る → 所有する」→ possess、possession。sedentarius → sedentary「座りがちな」。session（会合・時間枠）も「座って開く会」。⚠️ site・situation は situs「位置」から来ており、sedere ではない。

-vac- / -void-空；空出空；空けるLatin vacare, vacuus; Old French vuide

来自拉丁语 vacare（空着、有空）和形容词 vacuus（空的）。vacare → vacate“腾出”、vacancy“空缺”、vacation“没有职责 → 假期”；本站已学的 vacant 也在这里。ex- + vacuus → evacuare“清空” → evacuation（本站已学 evacuate）；vacuum“真空 → 吸尘器”。到了古法语，相关的词变成 vuide → void“空的、无效的”；des- + vuidier → devoid“完全没有”；es- + vuidier → avoid“清空、离开 → 避免”，unavoidable。⚠️ vaccine（疫苗）来自 vacca“母牛”（最早的牛痘疫苗），和 vac“空”不同源。ラテン語 vacare（空である・暇である）と形容詞 vacuus（空の）から。vacare → vacate「明け渡す」、vacancy「欠員・空室」、vacation「職務がない → 休暇」。既習の vacant もここ。ex- + vacuus → evacuare「空にする」→ evacuation（既習 evacuate）。vacuum「真空 → 掃除機」。古フランス語では関連語が vuide になり → void「空の・無効の」。des- + vuidier → devoid「全くない」。es- + vuidier → avoid「空にする・立ち去る → 避ける」、unavoidable。⚠️ vaccine（ワクチン）は vacca「雌牛」（最初の牛痘ワクチン）から来ており、vac「空」とは別語源。

-cis- / -cide-切；杀切る；殺すLatin caedere, -cisus; -cida

来自拉丁语 caedere（切、砍、杀），在合成词里变成 -cidere，过去分词 -cisus。de-“离开” → decidere“切断 → 了结” → decide、decision、decisive、indecisive；prae-“在前” → praecisus“切掉前端 → 简短精确” → precise（本站已学 precision）；con-（加强）→ concisus“切短的” → concise；in-“向内” → incisus“切入” → incisive“一针见血的”。“杀”的意思做后缀 -cide：pesticide（杀虫剂）、herbicide（除草剂）。⚠️ Day 15 的 -cid- / -cas- 来自另一个动词 cadere“落下”（incident、coincide、occasional），拼写很像，但意思和词源都不同。ラテン語 caedere（切る・打つ・殺す）から。複合語では -cidere、過去分詞 -cisus になる。de-「離して」→ decidere「切り離す → 決着をつける」→ decide、decision、decisive、indecisive。prae-「前で」→ praecisus「先を切り落とした → 簡潔・正確な」→ precise（既習 precision）。con-（強意）→ concisus「切り詰めた」→ concise。in-「中へ」→ incisus「切り込んだ」→ incisive「鋭い」。「殺す」の意味は接尾辞 -cide に：pesticide（殺虫剤）、herbicide（除草剤）。⚠️ Day 15 の -cid- / -cas- は別の動詞 cadere「落ちる」（incident、coincide、occasional）から。つづりは似ているが意味も語源も違う。

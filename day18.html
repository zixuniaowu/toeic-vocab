-grat- / -gree-令人愉快；感谢喜ばしい；感謝Latin gratus

来自拉丁语 gratus（令人愉快的、感激的）。grateful（感激的）、gratitude（感激之情）；con- + gratulari → congratulate“一同表示喜悦 → 祝贺”；gratus + facere → gratify“使满意”，gratifying“令人欣慰的”；un- + grateful → ungrateful。经古法语 gré“喜好”变成 -gree-：agree（使满意 → 同意）、agreement、agreeable。Day 8 学过的 gratuity（小费）也属于这个家族。⚠️ great（伟大的）、grate（磨碎；炉栅）与 gratus 无关；grade（等级）是 Day 4 的 grad“步”，也不同源。ラテン語 gratus（喜ばしい・感謝している）から。grateful（感謝している）、gratitude（感謝の気持ち）。con- + gratulari → congratulate「共に喜ぶ → 祝う」。gratus + facere → gratify「満足させる」、gratifying「喜ばしい」。un- + grateful → ungrateful。古フランス語 gré「好み」を経て -gree- に：agree（気に入る → 同意する）、agreement、agreeable。Day 8 の gratuity（チップ）も同じ仲間。⚠️ great（偉大な）、grate（すりおろす；火格子）は gratus と無関係。grade（等級）は Day 4 の grad「歩む」で別語源。

-prim- / -prin-第一第一のLatin primus, princeps

来自拉丁语 primus（第一的）。primary（主要的、首要的）、primarily（主要地）、prime（首要的、最好的）、primitive（原始的）、primer（入门书；底漆——最先刷的一层）；经法语变成 premier（首屈一指的；总理）。primus + capere“拿”（Day 4 的 cap）→ princeps“拿第一份的人 → 首领”：principal（主要的；校长；本金）、principle（原则、根本）。⚠️ principal 与 principle 同音：principAL 可作形容词“主要的”，principLE 只是名词“原则”。⚠️ prior / priority 来自另一个拉丁词 prior“在先的”，不要硬算进 prim 家族。ラテン語 primus（第一の）から。primary（主要な）、primarily（主に）、prime（最も重要な・最良の）、primitive（原始的な）、primer（入門書；下塗り＝最初に塗る層）。フランス語を経て premier（随一の；首相）。primus + capere「取る」（Day 4 の cap）→ princeps「最初の取り分を取る者 → 首長」：principal（主要な；校長；元金）、principle（原則・根本）。⚠️ principal と principle は同音。principAL は形容詞「主要な」にもなり、principLE は名詞「原則」のみ。⚠️ prior / priority は別のラテン語 prior「先の」由来なので prim の仲間に数えないこと。

-tact- / -tang- / -ting- / -teg-接触触れるLatin tangere, tactus

来自拉丁语 tangere（触碰），过去分词 tactus。con- + tangere → contact（接触、联系）；in-“不” + tactus → intact“未被碰过 → 完好无损”；tact“触觉 → 分寸”→ tactful（得体的）；tangible“可触摸的 → 切实的”，intangible（无形的）。在复合词里 -tang- 变成 -ting-：contingere“接触、碰巧发生”→ contingent（取决于……的）、contingency（意外情况）。in- + tangere → integer“未被触碰的 → 完整的”：integrate（整合）、Day 2 的 integrity（正直）。⚠️ tactic（战术）来自希腊语 taktikos“排列”，与 tangere 无关；tangent（切线）倒是同源。ラテン語 tangere（触れる）、過去分詞 tactus から。con- + tangere → contact（接触・連絡）。in-「〜ない」+ tactus → intact「触れられていない → 無傷の」。tact「触覚 → 機転」→ tactful（気配りのある）。tangible「触れられる → 具体的な」、intangible（無形の）。複合語では -tang- が -ting- に：contingere「触れ合う・偶然起こる」→ contingent（〜次第の）、contingency（不測の事態）。in- + tangere → integer「手つかずの → 完全な」：integrate（統合する）、Day 2 の integrity（誠実さ）。⚠️ tactic（戦術）はギリシャ語 taktikos「配列」由来で tangere とは無関係。tangent（接線）は同語源。
